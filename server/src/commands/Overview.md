# Commands Overview

## 도메인 폴더

- `community/`: 일반 채팅 명령, 우편, 파티, 거래.
- `economy/`: 연금술, 제작, 낚시, 단조, 상점.
- `operations/`: 관리자, 밸런스 진단, 패치노트.
- `player/`: 캐릭터 상태, 성장, 스킬, 직업, 랭킹, 튜토리얼.
- `world/`: 장소, 지도, NPC, 퀘스트, 퍼즐, 속성표, 전문 도감.
- `index.ts`: 모든 도메인의 초기화 함수를 호출하는 유일한 조립점.

`career.ts`의 `/직업`은 원래 메인→엘리트→3차 계보와 Lv.500 아르덴 시험 조건을 함께 표시하고, `player.ts`의 `/상태창`도 3차 표시명과 원래 엘리트/메인 계보를 잃지 않는다. `/직업정보`의 빈 지급 목록 문구는 모든 직업 티어에 맞는 중립 표현을 사용한다.

PVP 조작은 `player.ts`의 `/대상지정p`(`tgp`)와 `/공격p`(`ap`)에서 순번·닉네임·`#고유번호`를 받고 Player의 지역/파티 공격 검증 API를 사용한다. `location.ts`의 `/위치`는 위험도·PVP 여부·대상 버튼을 함께 표시한다.

채팅에서 들어온 `/명령어` 또는 첫 단어가 등록된 별칭인 슬래시 없는 입력을 검증된 게임 동작으로 연결한다. 모든 명령은 `modules/communication/bot.ts::registerCommand()`로 등록하고 `index.ts::initAllCommands()`가 분류별 초기화 함수를 호출한다.

- `general.ts`: 도움말, 권한별 등록 별칭을 보여주는 `/단축키목록`, 정보 열람 공개/비공개 모드, 랜덤, 공지, 관리자 eval. `/채팅청소 [개수|전체]`는 일반 사용자의 개인 채널 서버 기록과 관리자의 현재 일반 채널 공개 기록을 지우고, `/화면청소 [개수|전체]`는 서버 기록을 유지한 채 본인 화면만 비운다. 도움말의 구분선은 공용 divider ChatNode, 인자·설명은 light/dark 공용 테마 token으로 출력한다. 공개 추첨용 `/랜덤`만 조작 명령 중 입력과 결과를 현재 채널에 함께 공개한다.
- `player.ts`: 상태/인벤토리/아이템/장비/대상/공격/스탯. `/자동공격(autoattack, aa)`은 현재 타겟을 기본 공격 cooldown마다 공격하는 접속 중 모드를 토글하고 HUD snapshot과 퀵 버튼이 상태를 공유한다. 아이템 사용은 `ActionType.ITEM_USE` 제한을 검사하고 실제 수량이 소비된 뒤 `item:used`를, 유효한 대상 지정은 `combat:target_selected`를 발행한다. `/인벤토리정리 [자동|종류별|이름순]`은 목록형 인자로 `Inventory.sortItems`만 호출하며 생략 시 자동 기준을 사용한다. `/버리기 <슬롯> [개수|전체]`는 현재 Location에 snapshot을 옮기고 `/소각 <슬롯> [개수|전체]`는 같은 안전한 인벤토리 반출 경계를 사용한 뒤 영구 폐기한다. 장착·대상·스탯 분배의 최소 단축은 `eq/t/r`이고 스탯 분배는 `st`도 유지한다. 버리기·소각·장착·장착 해제는 입력과 결과를 모두 본인에게만 표시한다. 상태창은 상세보기를 열기 전에도 EXP·위치·골드·직업 기본 정보를 표시하고 모든 영역 제목을 공용 divider로 구분한다. 상세 영역의 생명력은 타입별 보호막을 겹쳐 그리는 공용 health 노드를 사용한다. 스탯은 각 값 옆에 실제로 올리는 파생 능력치를 표시하고 `/스탯분배`도 같은 목록을 사용해 제련 정밀도 같은 보조 수치의 누락을 막는다. 방어력·마법 저항력 툴팁은 현재 수치의 고정 방어와 비율 방어를 나눠 표시한다. 자원과 능력치는 `AttributeType.icon`을 붙인 한 행 목록으로 출력해 긴 이름의 두 열 겹침을 방지한다. `/대상지정`과 `/공격` 자동완성은 생존 대상을 먼저, 사망·파괴 대상을 뒤에 표시하고 `entity:boss`에는 레벨·이름 앞 왕관을 붙인다. 상태창 맨 아래는 효과 아이콘·시간·hover 설명을, 장착/인벤토리는 아이템 아이콘과 내구도를 표시한다. 인벤토리 현재/최대 중량은 공용 formatter의 `kg` 단위를 사용한다.
- `karma.ts`: `/카르마(karma/krm)`로 자연 감소가 반영된 현재 값·클래스형 악명 단계·`🥀` 여부와 주요 제한 기준을 정보 공개 모드에 맞춰 표시한다.
- `patchNotes.ts`: `/패치노트(patchnotes/pn) [버전]`으로 최신 또는 지정 버전·날짜만 채팅에 요약하고, `[+]` 추가·`[/]` 수정·`[-]` 삭제 전체 기록은 스크롤 가능한 상세보기 안에 표시한다.
- `inspection.ts`: `/감정`의 인벤토리 번호·장착칸 해석, `/몬스터정보`의 현재 장소 번호 조회와 감각 50 이상의 `/상태이상정보 <이름> [레벨]`을 제공한다. 감각 최소 요구치와 3단계 공개 범위를 검사하고 Item/Monster/StatusEffect snapshot을 표시명·아이콘·게임 수치·해석된 효과로만 변환해 내부 ID·raw 태그와 metadata를 숨긴다. 음식·물약·미궁 유물·스탯 환급권·감정표현 뽑기권·연금 조제약은 모호한 고유 효과 문구 대신 실제 회복량·효과명·레벨·지속시간·한도를 표시한다. 보스 몬스터의 자동완성과 정보 제목에는 레벨·이름 앞에 금색 왕관을 표시한다. 상태이상 정보는 정식 표시명을 alias보다 먼저 해석해 `독`과 `맹독`을 구분하고, 선택 레벨의 결과값과 hover 계산식을 표시한다. 아이템 단위·합계 중량은 `kg`로 표시하고 공용 상한의 stackable 아이템은 거대한 숫자 대신 `스택 제한 없음`으로 안내하며, 같은 능력치의 고정/비율 modifier는 합산·곱산 요약해 한 행에 표시한다. 감각 75 이상의 모든 장비(주무기·보조무기·방어구·장신구·가방)는 실제 교체 대상 슬롯의 최종 능력치 증감을 아이콘과 함께 `착용 시 변화` 마지막 구역에 표시하며 비장비와 하위 감각 단계에는 구역 자체를 숨긴다.
- `fishing.ts`: `/낚시(fish/f)`에서 낚시 서비스 공개 API를 호출하고, 미끼 미장착 시 인벤토리 묶음 자동 장착을 포함한 대기 시작 또는 장소·장비·미끼 오류를 본인에게 안내한다. `/낚시등급표(fishrate/fr)`는 현재 행운을 `getFishRarityChances()`에 적용한 등급별 실제 확률을 표시하고 `/낚시도감(fishbook/fb)`은 영속 어종 수집·단계 보상 현황을 등급별 접이식 목록으로 표시하며 미수령 일반·전투 보상을 소급 지급한다.
- `mailbox.ts`: `/우편함`, `/우편읽기 <번호>`, `/우편수령 <번호|전체>`, `/우편정리`를 모두 개인 카드로 제공한다. 목록·상세 카드 버튼도 같은 stable DB 우편 번호를 사용하며 미수령 첨부는 정리하지 않는다.
- `cosmetics.ts`: `/프레임목록`, `/프레임설정`과 `/감정표현` 목록·Gold 구매·사용을 제공한다. 30종 감정표현 목록은 문자 이모지가 아니라 공유 이미지 key의 투명 PNG를 표시하며 실제 전송은 서버가 보유권을 검증한 `emote` 노드를 사용한다.
- `location.ts`: Monster/Resource 통합 위치 조회, 오브젝트 상호작용, 바닥 아이템의 부분·개별·전체 줍기(`/줍기 <번호> [개수]`, `p`)와 취소 가능한 이동. 줍기 입력과 획득 결과는 본인에게만 보이며, 바닥 아이템 목록·자동완성·획득 결과는 `Location.getDroppedItemDisplays()`와 Item 표시 API를 사용해 단조·명명 metadata가 적용된 인스턴스 이름을 노출한다. `/이동(mv/v)` 입력·시작·진행·도착 피드백은 항상 본인에게만 전송하며, `ActionType.LOCATION_TRAVEL` 제한을 검사하고 연결 순번·장소 ID·구분 기호 없는 이름·유일한 부분 이름을 허용한다. `/자동이동(nav/ago/av/amv)`은 표시 가능한 방문 장소를 검색해 현재 열린 연결의 A* 최단 거리 경로를 이동하고, `/이동취소(vc/mvc/goc)`는 단일 이동과 자동이동을 모두 중단한다. 잠긴 길을 실제 시도하면 공개 가능한 잠금 사유를 안내한다. `/위치(l/m)`는 정보 공개 모드를 따르고 제압된 오브젝트는 붉은 상태로 표시한다.
- `travelHub.ts`: `/중계소 [목적지]`와 짧은 별칭 `/ㅈㄱㅅ`, `/th`는 현재 공간 중계핵에서 해금 상태·선행 퀘스트·해금 비용·목적지 사용료를 표시하고 서비스 결과로만 순간이동한다. `/중계소개방`은 현재 거점만 영구 해금하고 `/거주점`, `/거주점설정`은 해금된 현재 중계소를 사망 후 부활 위치로 지정한다. 명령은 TravelHub snapshot·명령형 API만 사용한다.
- `shop.ts`: 상점(`sh`) 조회, 구매(`bu`), 판매. 모든 경로가 Shop 카르마 접근 API와 Inventory predicate 수량·제거 API를 사용하며 목록과 구매 결과에는 다인원 보정이 적용된 실제 공유 재고 상한을 표시한다.
- `admin.ts`: 권한 10의 플레이어/월드 관리 명령. `/카르마설정`은 온라인·오프라인 Player의 공개 API와 dirty 저장을 사용하고, `/상태이상부여`는 온라인 대상만 조회해 `Entity.applyStatusEffect` 공개 API를 호출하며, `/레벨조정`은 `Player.adjustLevel`로 레벨 차이의 자동 스탯·분배 포인트까지 함께 증감한다. `/우편발송 <유저ID|me|online|all> <아이템ID> <수량> [제목]`은 정확한 소문자 예약어를 받고 대상 자동완성을 `me` → `online` → `all` → 중복 제거한 온라인 ID 순서로 제공한다. 단일은 `sendSystemMail()`, 실행 시점 온라인 snapshot은 ID를 정렬·중복 제거하는 `sendSystemMailToRecipients()`, 오프라인을 포함한 전체 캐릭터 `Player` 행은 `sendSystemMailToAllPlayers()`로 발송한다. `all`은 `User` 전체가 아니며, `sourceKey` 없는 반복 실행은 새 우편을 만들고 0명·수신자 수·성공·실패 결과는 관리자에게만 표시한다.
- `balance.ts`: 권한 10의 `/스킬밸런스(sb)`, `/직업밸런스(jb)`, `/아이템밸런스(ib)`, `/밸런스프로파일(bp)`. 개별 계산 외에 레벨별 추천 장비와 동레벨 일반/보스, 평타+전체 스킬 공유 자원 로테이션을 실행한다. 평균 DPS와 실제 누적 피해 처치 시각, 최대 단발·첫 반격 전 폭딜, 양쪽 HP, 대상 평타·최대 보스 기술, 피격 회피·확정 회피 가동률, 무회피/회피/방어기 포함 생존과 처치 후 예상 생명력을 함께 표시하며 `전체`는 공용 `BALANCE_PROFILE_LEVELS`의 Lv.20/50/75/100/140/180/200 구간을 비교한다.
- `progress.ts`: `/통계`로 공개 Progress snapshot을 공개 또는 비공개 표시한다. 속성 몬스터 처치 통계는 `/속성표`와 같은 기존 아이콘을 이름 앞에 표시한다.
- `codex.ts`: `/도감 [일반몬스터|보스|광물|탐험|요리]`로 다섯 전문 도감의 진척·영구 rank 보너스를 요약하거나, 발견한 이름만 노출하는 현재 횟수·동은금 목표를 40개 단위 접이식 목록으로 표시한다. 인자 없는 요약은 기존 `/낚시도감`이 별도 전문 도감임을 안내한다.
- `title.ts`: `/칭호목록(tl)`의 보유 조건·패시브·장착/활성 상태와 `/칭호장착(te/tu)`, `/칭호장착해제(tue)`. TitleBook snapshot과 명령형 API만 사용하며 목록은 정보 공개 모드를 따른다.
- `admin.ts`: 권한 10 관리 명령 중 `/칭호부여 대상 칭호(titlegrant)`와 `/칭호삭제 대상 칭호(titlerevoke/titledelete)`는 온라인·오프라인 Player를 같은 `TitleBook.grant/revoke` API로 변경하고 즉시 저장한다.
- `ranking.ts`: `/순위 [카테고리]`(`rank`, `ranking`, `rk`)의 공개 참가자 공동 순위·상위 5명 강조·고정 너비 열 UI와 `/순위공개`, `/순위비공개`, `/순위공개정보`의 전체 기본값·카테고리 예외 설정을 제공한다. 비공개 참가자는 실제 순위·수치를 숨기고 공개 순위 뒤의 별도 구역에 표시한다.

도움말·단축키목록·패치노트·상태창·인벤토리·감정·몬스터정보·상태이상정보·통계·도감·순위·순위공개정보·스킬/퀘스트/직업 정보·목록·상점·제작법·연금술법·연금재료정보·위치·지도·속성표·낚시등급표·낚시도감·파티정보는 `information: true`로 등록한다. 공개 모드에서는 입력과 결과가 현재 채널에 보이고, 조작 명령은 이 설정의 영향을 받지 않는다.

일반 조작 명령의 입력은 `showCommandUse`를 생략하면 본인에게만 표시한다. 공개가 필요한 명령은 `show`, 중복 입력 표시가 불필요한 버튼·스킬 명령은 `hide`를 명시하며, 비공개 결과를 반환하는 명령에 `show`를 사용하지 않는다.

`/사용`은 사용자용 인벤토리 번호 외에 아이템 퀵 HUD가 보내는 `item:<itemDataId>` 내부 입력을 받아, 현재 슬롯이 바뀌어도 같은 사용 가능 아이템 정의의 첫 인스턴스를 사용한다.

`/버리기`와 `/소각`의 `[개수|전체]`는 기본 1개를 사용하고 요청 수량이 보유량을 넘거나 `전체`이면 해당 인스턴스 전부를 반출한다. 소각은 바닥 snapshot을 만들지 않는다. 파티 초대 자동완성은 레벨 순위를 비공개한 온라인 플레이어의 레벨을 설명에서 생략한다.

캐릭터 귀속 `ItemData.bound` 아이템은 snapshot을 만들기 전에 `/버리기`와 `/소각`에서 거부하며, 거래 서비스도 에스크로 이동 전에 같은 제한을 검사한다.

명령 이름·인자·권한·자동완성·표시 방식이 바뀌면 이 문서와 [`docs/systems/chat-command.md`](../../../docs/systems/chat-command.md)를 갱신한다.
