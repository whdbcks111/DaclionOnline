# 테스트2 Application

`initTest2()`는 공통 세션과 참가 연결을 검증하고 test2 이벤트를 연결한다. 공용 맵은 최대 32명이며 ID와 닉네임은 서버 세션에서만 가져온다. 다른 게임에 참가한 같은 소켓은 거절한다. 입력은 초당 60회, 채팅은 계정당 3초 3회, 입장/체크포인트 복귀는 분당 12회로 제한한다.

`updateTest2(dt)`는 기존 20Hz 게임 루프에서 호출한다. 최대 200ms 누적을 1/60초 substep으로 처리하고 20Hz volatile snapshot을 보낸다. 세션 폐기/로그아웃/연결 종료에서 참가를 정리하고 빈 world를 폐기한다. 게임용 별도 timer나 DB row는 없다. 실제 두 소켓 통합 테스트가 입장과 이동, 말풍선/퇴장을 검증한다.
