# Data Overview

`locations.json`의 276개 장소는 안전·중립·적대 위험도를 구분한다. 초반 초원·은빛그물 숲·늪·화산·갱도부터 Lv.500 종언성단까지 이어지며 후반 권역은 분기·순환·합류 경로를 가진다. 분기형 성장 관문은 각 우회 진입 연결에도 같은 공개 레벨 조건을 둬 잠금을 우회하지 못하게 하며, 홍염산지·황혼왕릉에서 천둥마루로 진입하는 두 연결은 모두 Lv.50을 요구한다. Lv.380/420/460 관문은 각각 성운회랑·동결시계원·종언성단의 시작을 제한한다.

서버 시작 시 import 부작용으로 런타임 레지스트리에 들어가는 마스터 데이터를 둔다.

직접 속성 기술은 `skills.ts`에서 단일 공격 `effectTags`를 전달해 그림자 추격 같은 비투사체 공격도 표시된 속성대로 실제 상성을 적용한다.

v1.0.8 데이터는 수정 광맥의 `마나 수정` 드롭과 `마력 제련 → 정제 마나 수정` 경로를 추가한다. 전용 아트 제작 전까지 두 아이템은 존재하는 마나 포션 아이콘을 명시적 fallback으로 사용한다. 정제 마나 수정은 제작 성장형 마법력·최대 정신력·마법 관통 단조 재료이며, `마력 보호막`은 모든 피해를 막는 일반 보호막을 생성한다. 상태이상 계산 필드는 선택 레벨의 최종값과 사용자용 계산식 tooltip을 함께 정의한다.

v1.0.10 데이터는 소모품·재료·탄약·물고기·미끼·스킬북 등 모든 stackable 마스터 아이템의 작은 개별 제한을 공용 DB 안전 상한으로 통일한다. 실제 휴대 가능 수량은 인벤토리 최대 중량이 제한한다.

v1.0.9 데이터는 Lv.1~345 안전 거점의 최대 중량 성장 가방 11종과 일반·미궁·역근 유물함의 희귀 가방 3종을 추가한다. 전용 아트 제작 전까지 모든 가방은 하나의 128×128 가방 카테고리 fallback만 공유한다.

은빛그물 숲부터 월식해구까지의 지역 콘텐츠는 사냥·채굴 소재, 소모품, 다섯 역할 장비, 전승서, 자동 발견 조합법과 연속 퀘스트를 안전 거점에 연결한다. 역근수해 이후 세 권역도 지역별 소재 5종·소모품 2종·역할 장비 5종·가방 1종·광맥·7개 조합법·2개 연속 퀘스트를 제공하며 전용 아트 전에는 존재하는 카테고리 fallback을 명시적으로 재사용한다.

- `items.ts`: 아이템 이미지 key·`baseMetadata`·정의 태그·사용/공격 효과 등록. HP 회복은 `Entity.heal()`로 받는 치유량 상태효과를 반영하고 `restore_survival` 음식·음료는 배고픔/수분을 최대값 안에서 회복하며 `learn_skill` 스킬북은 신규 획득 성공 때만 한 개를 소비한다. 지각 붕괴와 은빛그물 보스의 포식자 도약·은실 사냥망 전승서가 같은 공개 handler를 사용한다. `apply_status_effect`는 metadata의 효과 ID·레벨·시간을 사용하며 전투 강장제·비전 영약·신속의 물약이 60초 버프를 제공한다. 미궁 유물은 전체 스킬 쿨다운 감소·잠기지 않은 인접 길 무작위 전이·다음 공격 확정 회피를 공개 API로 실행한다. 견습→성휘목→애도목 지팡이는 Lv.1~50 마법사 성장 단계에 맞춘 마법력·재생·투사체 가속을 제공한다. 가벼운 활→은빛그물 사냥활→진혼 시위→뇌운 시위는 같은 구간에서 동급 검보다 궁수 활 로테이션이 우세하도록 공격력·치명타·투사체 가속을 단계적으로 제공한다. Lv.50 이후 직업 무기 4종, 일반 제련 소재 5종과 홍염산지 전용 화맥 광석·홍염강, 조합형 단조 장비 형태 9종(무기·곡괭이·방패·머리/몸/다리/발 방어구), 버프 물약과 미궁 유물을 정의한다. 단조 방어구는 머리·몸통·각반·철갑화 전용 카테고리 아이콘을 사용하고, 가죽·실·식물·뼈/뿔·마력핵·휘장·비늘/갑각·기계부품 소재도 용도별 128×128 fallback을 공유한다. Lv.380~500 역할 장비는 `gameplayEffects`와 적중/피격 callback으로 둔화·방어력 감소·기절·빙결·정신력 회복·보호막을 실제 발동한다. 기본 미끼 조합에서 입질까지 약 31~45초가 걸리는 초보자 낚싯대·정교한 균형형 낚싯대, 보물상자 전용 범위/속도 특화 낚싯대, `/낚시` 시 묶음 자동 장착 지렁이 미끼와 `fishingCatalog.ts`의 물고기 아이템도 정의하며 인스턴스는 기본 metadata 전체를 복사하지 않고 top-level delta만 저장한다.
- `items.ts`의 성장·희귀 가방은 `item:bag` 태그, 독립 `bag` 슬롯과 최대 중량 modifier를 가지며 하나의 카테고리 fallback을 공유한다.
- `projectiles.ts`: 코드에서 참조하는 투사체 마스터 데이터. 재료 속성을 공격 상성으로 쓰지 않는 중립 물리 화살, 현재 마법력의 108%를 사용하는 무탄약 지팡이 기본 공격용 마력 구체, 마법사 스킬 전용 마력탄을 각각 독립 정의하고 owner 투사체 가속 반영 계수를 가진다. 스킬이 지정한 회피 불가 오버라이드는 투사체 비행 뒤 실제 적중 공격까지 유지된다.
- `monsters.ts`: `/몬스터정보`에 쓰는 설명과 Lv.1~500 몬스터의 전투 속성·상태이상·능력치·보상·드롭 정의. 모든 마스터는 역할 `MonsterStatProfile`과 체급 `MonsterRank` 메타데이터를 가지며 Lv.380 이후 몬스터는 레벨 예산+weight/override API를 사용한다. 각 정의의 기본 이미지 key는 `monsters/{id}`이고 현재 158종 모두 서로 다른 64×64 RGBA 초상 아이콘을 가진다. 일반 동급 경험치는 생활 콘텐츠도 재사용하는 `Entity.getStandardMonsterExpOfLevel(level)`의 `level × 20`이며 성장 관문과 선택 권역 보스는 5배 이상 경험치·고체력·전용 SkillData 또는 미니게임 패턴을 가진다. Lv.400/440/480 중간 보스는 순차 패턴, Lv.420/460/500 권역 보스는 위협도 기반 대상 선택과 무작위 패턴을 사용한다.
- `bossPatterns.ts`: 은빛그물 알주머니, 태양거울·역설 고정자·공허왕관 기둥·백야 조류거울의 생존 여부에 따른 보스 피해 경감과 수정맥·철근·성계 보스의 미니게임 패턴을 소유한다. 조류거울이 하나라도 남아 있으면 백야대사제는 받는 피해를 65% 줄인다.
- `resources.ts`: 비공격 Entity 자원의 능력치, 공격 가능 여부, 광맥 경도, 가중치 드롭, 범위 경험치, 상호작용·랜덤 쿨타임 정의. 광맥은 곡괭이 없이도 공격할 수 있으며 물리·마법 공격 타입의 기본 효율과 공격자의 채굴력으로 실제 피해 배율을 계산한다. 바람결 초원의 훈련 목인, 역근수해의 보스 기믹과 더불어 경도 650/730/820의 혜철·진자강·소멸금 광맥을 포함한다.
- `shops.ts`: 기존 상점과 Lv.500까지의 권역 안전 거점 상점 태그·매매 목록·재고 정의. 루미나르 잡화점은 견습 지팡이와 180골드의 Lv.20 성장용 성휘목 지팡이를 판매하며 잡화점·낚시상점은 lawful 카르마 제한을 적용한다. 루미나르부터 종언성단까지 각 성장 거점은 해당 구간 최대 중량 가방을 제한 재고로 판매한다. 지역 상점은 해당 구간 역할 장비·생존품을 판매하며 지역 소재를 희귀도에 따라 매입한다.
- `fishingCatalog.ts`: 일반~신화 각 6종, 총 36종 물고기의 ID·이름·설명·중량·등급 단일 원본.
- `fishing.ts`: 공용 물고기 카탈로그를 낚시 보상 registry에 등록한다.
- `tagEffects.ts`: `source tag → target tag → modifier` 단방향 효과 테이블과 `/속성표`용 라벨·`affinities/*` 아이콘 key. 불·물·얼음·자연·독·전기·돌·어둠·빛·언데드·신성·벌레·금속·땅과 무생물을 모두 매핑한다.
- `statusEffects.ts`: 레거시 상태이상을 현재 source modifier·행동 제한·피해 API로 이식한 마스터 정의. 쇠약의 저주는 공격/마법/치유 효율을, 석화는 전투·이동 행동과 방어 성향을, 열병은 속도·수분 유지를 조절한다. 화염/빙결·열병/빙결·둔화/신속 중화와 저항·해독·보존·발각 단방향 상호작용 표를 함께 소유한다. 전용 아이콘 제작 전에는 의미가 가까운 기존 아이콘을 명시적으로 공유한다.
- `locations.json`: 초반 루미나르부터 종언성단까지의 좌표·연결·대표색·통합 오브젝트 원본. Lv.380 이후 성운회랑 14곳, 동결시계원 14곳, 종언성단 15곳은 각각 하층과 상층의 갈림길·합류 및 두 보스 동선을 가진다. 같은 월드 권역의 장소는 지도에서 하나의 연속 면으로 합쳐지도록 동일한 `mapColor`를 공유한다.
- 은빛그물 숲은 바람결 초원 2에서 분기해 사냥꾼 거점·적갈기 언덕·독실 동굴을 거쳐 안개수렁에 재합류하며, 여왕 산란실의 알주머니 3개가 보스 피해를 35% 경감한다.
- `locations.ts`: Lv.10/20/28/36/45/50/70/90/120/150/180/200/235/275/310/345/380/420/460 연결 condition handler와 실제 이동 실패 시 공개할 필요 레벨 설명 등록.
- `dungeonPuzzles.ts`: 기존 질문 퍼즐과 월식 조류제단의 해답 Progress, Resource interaction과 hidden 경로 condition을 연결한다.
- `progress.ts`: 게임 이벤트에 연결되는 통계 정의. 공개 치명타 누적, 전체 PVP 처치와 반복 처치 방지 조건을 통과한 유효 PVP 처치, 숨김 검·도끼·활·단검·지팡이 적중 횟수가 있다.
- `progress.ts`의 숨은 `security:human_verification_required/failures`는 반복 사냥 사람 확인의 재접속 복원과 운영 실패 기록을 기존 PlayerProgress dirty 저장으로 유지한다.
- `progress.ts`의 숨은 `profession:blacksmith` flag는 구형 독립 대장장이 데이터를 정식 직업 슬롯으로 이전하는 호환 값이다.
- `titles.ts`: 레거시 획득 가능 칭호 16종과 신규 사냥·보스·채광·낚시·단조·원소 칭호 6종, 태그 기반 처치/행동 통계와 장착 패시브 정의. PVP 칭호는 유효 처치만 세어 학살자 100킬에서 몰살자 500킬로 순차 성장한다. `entity:wolf` 등 대상 태그, source 능력치·경험치 modifier와 실제 피해 후 기절·출혈 CombatPipeline hook을 사용한다.
- `skills.ts`: 아이콘 key·스킬 마스터 metadata·계산 필드·포맷 문자열·Entity 공용 획득/발동/패시브 수명주기와 실제 계수 callback을 공유하는 밸런스 진단 metadata. 공개 기술 계열 표시 metadata와 전사/궁수/암살자/대장장이 0.75초, 모든 마법 0.5초, 동일 화염·빙결·전격 1초의 태그 기반 공유 쿨다운을 정의하며 엘리트 액티브도 메인 계보를 따른다. 공용 강타는 검·도끼·단검·곡괭이 전용이며 활·지팡이의 투사체 규칙을 근접 공격으로 우회하지 않는다. 궁수는 현재 공격력+이동속도, 암살자는 현재 이동속도+공격력, 마법사는 마법력과 방어기 일부의 최대 생명력, 대장장이는 제련 정밀도 증폭을 공용 복합 계수 API로 계산해 장비·패시브·상태효과 버프도 즉시 반영한다. Lv.200에 Lv.1로 시작하는 조합 전용 액티브는 일반 성장기의 기존 기술보다 단발 위력이 낮아지지 않도록 직접 피해에 물리 3배·마법 4.6배의 명시적 엘리트 티어 보정을 적용하고, 하이브리드 마검사는 별도 데이터 보정값을 사용한다. 이 보정은 치명타·상태효과·보호막 점수와 분리되고 계산 tooltip에 함께 표시된다. 다섯 1차 직업은 Lv.30·50·75·100·140·180 `unlockLevel`에 공격·제어·방어 성장 기술을 자동 획득한다. 마법사는 속성 처치 30/100/200회와 선행 주문 Lv.3/3/4를 함께 만족해 화염·빙결·전격 상위 주문을 단계적으로 획득한다. 지역 보스는 직업 제한 없는 플레이어용 전승 기술을 별도 스킬북으로 제공한다. 역설기계고 전승 기술은 광자창·인과고정·톱니폭우·역설반전이며 시간강 거신과 역설설계자는 별도 몬스터 패턴 SkillData를 사용한다. 전투 본능·매의 눈·살의 감각·마력 순환·체력/감각형 대장장이의 담금질 1차 패시브와 20개 조합별 엘리트 계승 패시브는 직업 조건이 유효할 때 source-key modifier를 적용하고 비활성 시 정리한다. 대장장이는 최대 생명력과 치명타 피해가 함께 반영되는 확정 치명타 `결 파쇄`, 제련 정밀도에 따라 처리량과 캐릭터 경험치가 늘어나는 마력 제련을 사용하며 감각 250 이상이면 본인 제작 장비를 명명하는 `장인의 명명`을 자동 획득한다. 마도 대장장이는 무기 속성에 편향된 화염·맹독·기절·빙결·실명 중 한 적중 효과를 서버 난수로 한 번 부여한다. 은신은 공격·투사체 발사에 즉시 해제된다. 바람 회피는 이동속도에 따라 지속시간이 늘어나고, 지속 중 모든 일반 공격에 적용되는 확정 회피 source를 유지한다. 확정 아트 전에는 명시한 카테고리 fallback을 쓰고 시전 메시지가 있는 액티브는 의미가 맞는 기존 4:1 배너를 명시적으로 재사용한다. 효과 설명은 콘셉트·최종값·후속 효과 순서의 문장을 사용하고 피해·보호막 계수는 최종 숫자의 hover에 숨긴다. 발동 조건은 실제 준비할 항목만 표시하며, 주문과 자체 생성 투사체는 장비 독립적으로 발동한다. 몬스터 보스 기술은 같은 장소의 사용자에게 대응 정보가 포함된 시전 예고를 히스토리로 남기고, 공격 결과에는 기술명과 상태이상 레벨·지속시간을 포함한 전투 코멘트를 삽입한다. 직업 지속 버프와 스킬 고유 관통·회피 불가 값은 로테이션 진단에서도 실제 callback과 옵션을 공유한다. Lv.400~500 여섯 보스의 중력·낙성·시간정지·역행·성단붕괴 계열 13개 패턴 기술도 같은 SkillData 실행 경계를 사용한다.
- 마법 계열 보호막은 전용 방어기와 공격 후 부가 방벽을 구분한다. `마력 보호막`은 마법력·최대 정신력·최대 생명력과 Lv.50 이후 성장 보정을 모두 사용하고, 마법 계열 공격의 부가 방벽은 더 낮은 공통 계수로 같은 후반 성장을 따른다. 표시 tooltip·실제 보호막·밸런스 보고서는 동일 callback을 공유한다.
- `jobs.ts`: 전사·궁수·암살자·마법사·감각/체력 중심 대장장이 5개 1차 직업, 각 직업의 상시 패시브를 포함한 지급 스킬·메인/서브 modifier와 동일 직업을 제외한 순서 있는 20개 Lv.200 엘리트 조합 및 조합 전용 계승 패시브·액티브 지급. 엘리트 공격 보정은 메인 직업의 대표 계수가 서브 직업 계수보다 우선하도록 유지한 실제 추천 장비·전체 스킬 로테이션에서 1차·엘리트 보스 DPS 편차가 1.5배를 넘지 않도록 실측한 값이다.
- `crafting.ts`: predicate 재료·발견 조건·제작 시간·결과 factory 정의. Lv.380 이후 세 권역은 생존품 2종과 역할 장비 5종씩 총 21개 자동 발견 조합법을 더한다.
- 엘리트 대장장이 제작 확장: 마도 대장장이는 `지팡이 마력 부여`로 단조 틀을 완성 지팡이로 바꾸고, 기계 장인은 `정밀 병기 제작`으로 활대·화살촉 단조 형태와 강화 활시위·화살대·단조 활·단조 화살 조립법을 해금한다. 단조 부품과 완성품은 기존 카테고리 아이콘을 명시적 fallback으로 사용한다.
- `npcs.ts`: NPC ID, 조건부 진입점과 generator 대화 장면 정의. 새벽교단 고해사제의 헌금 속죄, 기존 권역 안내와 함께 성도항해사·영시계지기·종성관측자가 신규 연속 퀘스트를 안내한다.
- `quests.ts`: NPC 제공/보고 ID, 단계형 목표와 lazy 표시명 보상 정의. 튜토리얼·전직·기존 지역 연속 퀘스트에 Lv.380/420/460 소재 제출과 Lv.400~500 두 보스 토벌 퀘스트 6개를 더한다.
- 내구도가 있는 `items.ts` 마스터 아이템의 최대 내구도는 이전 기준의 1.5배다. `locations.json`의 전용 보스 전투 공간 31곳은 `location:boss_room` 태그로 입장 선공을 명시하고 야외 필드 보스 지역은 제외한다.

ID는 DB와 다른 데이터 파일에서 참조되므로 변경 시 참조 전체를 확인한다. 데이터 구조나 ID가 바뀌면 이 문서와 해당 [`docs/systems/`](../../../docs/systems) 문서를 갱신한다.
