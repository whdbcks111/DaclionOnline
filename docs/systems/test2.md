# 테스트2

GAME BOX의 세 번째 게임이며 `/games/test2/`에서 공통 계정으로 접속한다. 모두 같은 사이드뷰 점프맵에서 만나며 최대 32명이다. 별도 가입이나 캐릭터 생성은 없다.

## 맵과 이동

`shared/test2.ts` map v1은 241개 발판과 20개 체크포인트로 65,000px 이상 이어진다. 발판은 위에서만 착지하는 one-way 지형이며 발판 사이 높이차/간격을 제한한다. 자동 검증에서 모든 인접 발판을 실제 점프 물리로 통과한다. 시작 깃발은 0번, 12개 발판마다 체크포인트, 마지막은 완주 깃발이다.

이동 300px/s, 중력 1600px/s², 점프 속도 620px/s다. 60Hz 고정 substep에서 서버가 착지/낙하/체크포인트/완주를 판정한다. 절벽에서 떨어진 뒤 100ms까지 코요테 점프를 허용하며, 착지 전 140ms의 입력을 버퍼링한다. 증가하는 jump counter의 새 값만 점프를 요청하고 착지/코요테 점프는 버퍼를 소비해 공중 다중 점프를 막는다. 입력이 300ms 끊기면 수평 이동을 멈추고 중력은 계속된다. 플레이어끼리 충돌하지 않는다.

## 조작과 UI

A/D와 좌우 방향키로 이동, Space/W/위 방향키로 점프한다. 모바일은 왼쪽 조이스틱과 오른쪽 점프 버튼을 제공한다. 화면 전체를 게임에 쓰고 Esc 메뉴에서 테마, 체크포인트 복귀, 나가기와 포털 이동을 제공한다. 메뉴는 본인의 조작만 멈추며 월드는 계속된다.

Enter/채팅 버튼은 중앙보다 살짝 아래에 채팅 폼을 연다. 한국어 IME 조합 중 Enter는 보내지 않고 Esc는 취소한다. 최대 120자의 메시지는 계정당 3초 3회로 제한하고 캐릭터 위 말풍선 하나로 5초간 표시한다. HTML/채팅 로그/DB 기록은 없다. UI/말풍선/카메라 투영은 `components/realtime-game/`을 SEED WALK와 공유한다.

## 상태와 수명

`Test2World`가 런타임 상태를 소유하며 마지막 연결 종료 시 플레이어를 제거한다. 위치, 체크포인트, 완주, 말풍선은 비영속이다. 재접속/서버 재시작 뒤 처음부터 시작하며 DB schema/dirty flush/기존 게임 진행 상태를 변경하지 않는다. fall y>1100 또는 메뉴 복귀는 마지막 체크포인트에서 다시 시작한다. 여러 탭은 같은 계정 캐릭터를 공유한다.
