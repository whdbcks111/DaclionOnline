# 직업·전직 시스템

## 구조와 해금

`JobData`는 코드 마스터 정의이며 `defineJob/getJob/getAllJobs` 정적 레지스트리로 찾는다. `JobTier`는 1차/엘리트/3차, `JobSlotType`은 메인/서브와 요구 레벨을 소유하는 클래스형 enum이다. Player의 `CareerProfile`은 내부 Progress key를 숨기고 직업 선택·계보 호환·능력치 modifier·스킬 지급·엘리트/3차 전직을 담당한다.

- 메인 직업: Lv.20부터 전직소 퀘스트 완료로 선택한다.
- 서브 직업: Lv.50부터 전직소 퀘스트 완료로 선택한다.
- 메인과 같은 직업은 서브로 선택할 수 없다. `CareerProfile.canAssign/assign`과 퀘스트 조건 양쪽에서 거부한다.
- 엘리트 직업: Lv.200에 서로 다른 메인→서브의 순서 있는 조합으로 자동 전직한다.
- 전사·궁수·암살자·마법사·대장장이·성직자 6개 1차 직업의 서로 다른 조합 30개가 모두 결과를 가지며 메인→서브 순서를 구분한다. 예를 들어 `마법사→성직자`는 연금술사, `성직자→마법사`는 빛의 사제다.
- 각 엘리트 직업은 전직 즉시 조합 전용 계승 패시브와 액티브 스킬을 하나씩 추가로 획득한다. 기존 메인·서브 스킬과 패시브도 함께 유지된다.
- Lv.240에는 메인 계보 상시 패시브, Lv.320에는 메인 계보 역할기를 자동 획득한다. 엘리트 직업은 원래 메인 계보의 두 성장을 유지하지만 서브 계보에서는 중복 획득하지 않는다.
- 3차 직업은 Lv.500에 정확한 메인·서브 조합의 엘리트를 보유한 플레이어가 전직소의 계승관 아르덴에게 장기 시험을 받아 완수했을 때만 계승한다.

## 3차 계승

원래 메인 계보별 3차 직업은 전사 `철혈군주`, 궁수 `성흔추적자`, 암살자 `월영집행자`, 마법사 `성계현자`, 대장장이 `신화장인`이다. 3차는 새로운 액티브를 늘리지 않고 고유 패시브 하나와 Lv.320 역할기 강화를 제공한다.

- 철혈군주: `선봉의 호령` 보호막과 도발 위력 +22%.
- 성흔추적자·성계현자·신화장인: 각각 `파갑 표식`·`마력 균열`·`구조 해체`의 non-CC 약화 +1레벨.
- 월영집행자: `종막`의 잃은 생명력 보너스 상한과 총 피해 상한 +18%. 기존 상한은 계속 적용된다.

3차 `parentJobIds`는 원래 1차 메인 하나만 가리킨다. 엘리트 선행 조건은 `CareerProfile.canPromoteThird`가 현재 메인·서브의 정확한 ordered 엘리트인지 별도로 검증하므로 서브 계보가 메인 스킬로 잘못 인식되지 않는다. 현재 3차 계보는 기존 다섯 메인 직업에만 정의되어 있으며 성직자 메인 3차는 이번 단계에 추가하지 않는다. `effectiveMainJob`은 3차 → 엘리트 → 1차 순으로 표시 직업을 선택하지만 원래 메인·서브·엘리트 ID와 지급 스킬은 모두 보존한다.

## 영속성과 계보

3차 ID는 기존 세 직업 상태와 함께 `career:third_job` Progress STATE로 저장한다. 로그인 복원은 원래 메인·서브와 정확히 일치하는 엘리트 및 3차만 유효하게 읽으며 별도 Prisma migration은 없다. 관리자 메인·서브 재설정은 3차 상태와 3차 패시브를 즉시 회수한 뒤 새 조합의 엘리트를 다시 계산한다.

메인·서브·엘리트 ID는 `career:main_job`, `career:sub_job`, `career:elite_job` Progress STATE로 저장한다. 변경은 메모리 dirty 상태로 남고 기존 30초/unload/종료 flush를 사용한다. 퀘스트 보고와 엘리트 전직은 중요한 변경이므로 `Player.save()`도 요청한다. 단, 로그인 복원 중 `CareerProfile.initialize()`는 생성자 중간에서 저장을 시작하지 않고 신규 엘리트 전직 여부만 반환한다. Player가 카르마·순위·생존 자원까지 모두 복원한 뒤 저장해 초기화되지 않은 필드 접근과 잘못된 값 저장을 막는다. 별도 Prisma migration은 없다.

엘리트 전직 뒤에도 원래 메인 ID와 서브 ID를 보존한다. `CareerProfile.hasJob(jobId, slot?)`은 엘리트의 `parentJobIds`를 따라 원래 메인 계보를 호환하므로, 마검사는 전사 메인 스킬과 마법사 서브 스킬을 계속 표시·사용할 수 있다. 스킬은 박탈하지 않고 `SkillData.jobRequirement`와 `isVisible/checkUsable`에서 표시·사용만 제어한다.

## 초기 직업과 스킬

직업별 권장 스탯 우선순위는 아래와 같다. 공격 스킬은 이 우선순위가 실제 계수 크기에 반영되며, 장비·패시브·상태효과로 증가한 현재 능력치도 같은 계수를 증폭한다.

| 직업 | 권장 우선순위 | 계수 방향 |
| --- | --- | --- |
| 전사 | 근력 > 체력 > 민첩 | 공격력·물리 관통·최대 중량 중심, 최대 생명력·이동속도 보조 |
| 궁수 | 근력 > 민첩 > 감각 | 공격력·물리 관통 중심, 이동속도 보조 |
| 암살자 | 민첩 > 근력 > 감각 | 이동속도 중심, 공격력·물리 관통 보조 |
| 마법사 | 정신력 > 감각 > 체력 또는 민첩 | 마법력 중심, 보호막은 최대 생명력 보조 |
| 성직자 | 정신력 > 감각 > 체력 | 마법력·최대 정신력 중심, 파티 회복·보호 보조 |
| 대장장이 | 감각 > 엘리트 방향 능력치 | 제련 정밀도가 공격·방어 계수를 증폭 |

- 전사: 패시브 `전투 본능`(공격력 +6%, 방어력 +6), 강철 베기, 전투 질주, 불굴. 검/도끼와 생명력·공격·속도 균형.
- 궁수: 패시브 `매의 눈`(치명타 확률 +4%p, 이동속도 +5%), 마력 화살, 다중 사격, 충격 화살, 바람 회피. 활 투사체·기절·임시 확정 회피.
- 암살자: 패시브 `살의 감각`(치명타 피해 +18%p, 방어 관통력 +4), 은신, 암습, 맹독 칼날. 이동속도·은신·회피 불가 치명타·맹독이 핵심이며 단검 숙련은 별도 장착 보너스다.
- 마법사: 패시브 `마력 순환`(마법력 +7%, 정신력 재생 +1.5/초), 마력탄, 마력 보호막, 원소 속박, 원소 통찰. 정신력·마법 방어와 제어. 지팡이는 마법력 기반 투사체 평타와 마법력·투사체 가속 증폭을 제공하지만 주문 사용을 제한하지 않는다.
- 성직자: 패시브 `새벽의 신심`, 빛 속성 투사체 `광휘탄`, 파티 지원기 `성역의 가호`. 성역의 가호는 현재 지정한 생존 파티원을 우선하고 같은 장소의 같은 파티원만 최대 3명까지 회복·보호하며, 솔로에서는 자신에게 적용한다. 다른 파티와 적대 플레이어는 대상이 될 수 없다.
- 대장장이: 패시브 `대장장이의 담금질`(최대 중량 +10, 최대 생명력 +8%, 치명타 피해 +20%p), 확정 치명타 `결 파쇄`, 마력 제련, 금속 단조. 체력으로 버티고 감각으로 금속의 결·급소·단조 박자를 읽는 생산·근접 혼합 직업이다.

패시브도 일반 스킬과 같은 `SkillData`/`SkillBook` 경계를 사용한다. 보유한 패시브는 스킬 목록과 정보창에 표시하지만 직접 사용 버튼과 전투 퀵 HUD에서는 제외한다. 직업 또는 계보 조건이 유효할 때만 source-key 능력치 modifier를 유지하며, 직업을 잃거나 스킬이 회수되면 `onPassiveInactive`가 즉시 정리한다. 전용 패시브 아이콘은 후속 아트 작업 전까지 각 직업 아이콘을 fallback으로 사용한다.

엘리트 계승 패시브와 액티브는 30개 ordered 조합마다 하나씩 존재한다. 연금술사는 이 전투 스킬 둘에 더해 조제 기능을 명시적으로 여는 최대 1레벨 패시브 `가마솥 연성`을 지급한다. 로드 중 `CareerProfile.initialize()`가 현재 직업의 지급 스킬을 멱등 복원하므로 패시브 추가 전부터 존재한 연금술사도 별도 DB migration 없이 획득한다. 실제 조제 권한은 현재 연금술사 직업과 패시브 보유를 함께 요구해 관리자 직업 변경 뒤 남은 과거 스킬만으로 사용할 수 없다. 성직자를 서브로 택한 선봉장·길잡이·검무사·연금술사·명장은 원래 메인 직업의 전투·생산 정체성을 유지한다. 성직자를 메인으로 택한 세인트 나이트·여명 순찰자·빛의 심판자·빛의 사제·성물지기는 빛과 교단의 보호·심판 방식을 각 서브 직업과 결합한다. `/직업밸런스`의 Lv.200 시나리오도 모든 조합의 실제 callback을 적용한다.

Lv.240 메인 계보 패시브는 전사의 `불퇴의 체질`, 궁수의 `궤적 해석`, 암살자의 `살수의 호흡`, 마법사의 `심층 마력순환`, 대장장이의 `명장의 열처리`다. Lv.320 역할기는 각각 도발·보호막 `선봉의 호령`, 물리 방어 약화 `파갑 표식`, 상한형 마무리 공격 `종막`, 마법 방어 약화 `마력 균열`, 양면 방어 약화 `구조 해체`다. 역할기는 20~30초 재사용 대기시간과 기존 계열 공유 쿨다운을 사용하고, 약화기는 10초 동안 방어만 낮춰 무한 행동 불가 연계를 만들지 않는다. 전용 아트 제작 전까지 기존 계열 아이콘과 배너를 명시적인 fallback으로 재사용한다.

같은 엘리트 직업이 지급하는 계승 패시브와 액티브는 스킬 목록에서 구분되는 고유 표시 이름을 사용한다. 비전 사신은 패시브 `영혼 포식`으로 마법력·치명타 피해를 높이고, 액티브 `비전 수확`으로 대상을 공격한다.

엘리트 액티브는 총 30종이다. 조합에 따라 회피 불가, 확정 치명타, 속성 투사체, 마비독·맹독, 보호막을 기존 전투 API로 조합한다. 복합 계수는 메인 직업의 대표 능력치를 가장 크게 유지하고 서브 직업의 대표 능력치를 보조·3차 계수로 더한다. 예를 들어 비전 사신은 암살자의 현재 이동속도와 공격력이 마법력보다 우선하며, 원소 사수는 공격력·이동속도가 마법력을 앞선다. 전용 아이콘 제작 전까지 주계열 직업 또는 채굴 도구 카테고리 아이콘을 fallback으로 사용한다.

대장장이를 메인, 마법사를 서브로 선택한 `마도 대장장이`는 공통 계승 패시브·액티브 외에 후가공 유틸리티 `마법 부여`와 생산 스킬 `지팡이 마력 부여`를 획득한다. 이 계보는 레벨과 무관하게 `/단조 지팡이 틀 <재료>`와 `/지팡이부여 <인벤토리 번호>`를 사용할 수 있고, 일반 대장장이도 Lv.200부터 같은 지팡이 제작 경로를 사용할 수 있다. 정신력 120을 소모해 완성한 지팡이는 마법 관통력·정신력 재생·투사체 가속을 얻는다. `/마법부여`로 상태이상, 추가 피해·투사체, 약타/강타 변동, 현재 생명력 비례 피해, 회복·보호막 중 하나를 한 번 각인하는 권한은 마도 대장장이에게 유지되며 `/마법부여효과`에서 후보를 확인한다. 전용 아트가 없으므로 지팡이/마법력 카테고리 아이콘을 fallback으로 사용하며 TODO로 관리한다.

대장장이를 메인, 전사를 서브로 선택한 `전투 대장장이`는 후가공 유틸리티 `장비 강화`도 획득한다. 철근미궁 지핵 수정실 전용 강화석으로 긍정 능력치가 있는 무기와 방어구를 +15까지 확률 강화한다. 강화 효과는 장비 원래 주·부가 능력치에 비례하며 +5/+10/+15에서 추가 보너스를 받아 누적 30%/60%/90%에 도달한다. +7부터 하락, +9부터 파괴 위험이 생기며 `/강화확률`에서 단계별 결과 확률을 확인한다. 기존 `/무기강화`는 `/장비강화`의 별칭으로 유지한다. 전용 아트 제작 전에는 공격력 능력치 아이콘을 fallback으로 사용한다.

대장장이를 메인, 궁수를 서브로 선택한 `기계 장인`은 `정밀 병기 제작`을 획득해 레벨과 무관하게 활대·화살촉 묶음 단조와 활·화살 조립을 사용할 수 있다. 일반 대장장이는 Lv.200부터 활대 단조, 강화 활시위 제작과 활 조립까지 사용할 수 있지만 화살촉 묶음·화살대·화살 조립은 기계 장인 전용으로 유지된다. 완성 활과 화살은 단조 부품의 이름·재료 속성·품질·공격 성능을 인스턴스 delta로 승계하고 기존 투사체 전투 API를 그대로 사용한다.

궁수의 물리·마법 화살과 마법사의 공격 마법 투사체는 발사 순간 시전자의 치명타 확률·치명타 피해를 복사해 적중 시 치명타를 판정한다.

직업 스킬은 `/스킬 이름`과 `activationMessage`/`activationPhrase`의 `이름!` 일반 메시지로 발동한다. `SkillData.weaponRequirement`는 검·도끼로 직접 타격하거나 활로 사격하는 등 무기가 기술 동작에 반드시 필요할 때만 `Equipment.hasEquippedItemTag`로 주무기 태그를 검사한다. 마법 주문, 환영 단검·자동 추적탄처럼 스킬이 직접 만드는 투사체에는 무기 제한이 없다. 암습·맹독 칼날·혈맥 절단·그림자 참수도 암살자의 기동·독·급소 공격 자체가 핵심이므로 특정 무기를 요구하지 않는다. 따라서 서로 다른 메인·서브 직업의 무기를 장착해도 다른 계열의 비무기 스킬을 함께 사용할 수 있다. 전직 보상으로 전사는 훈련용 도끼, 궁수는 가벼운 활, 암살자는 독 단검, 마법사는 견습 지팡이를 받는다.

전투 질주·불굴·바람 회피·은신·마력 보호막·원소 통찰은 발동 시 시전 문구와 현재 레벨 기준 상승량·지속시간을 상세 메시지 및 notification으로 알린다. 솔로에서는 본인에게만 보이고 파티 중에는 파티 전투 피드로 공유된다.

직업 스킬의 공격·버프 수치는 스킬 레벨에 따라 성장한다. 설명 본문에는 현재 플레이어 능력치와 스킬 레벨로 계산한 결과만 간결하게 표시하고, 수치 hover에는 `공격력 × 계수`, `이동속도 × 환산값 × 계수`, 기본값, 레벨당 증가량을 표시한다. 설명과 실제 발동은 `skills.ts`의 공용 복합 계수 계산을 함께 사용한다. 원본 Stat이 아니라 현재 Attribute를 읽으므로 전투 중 능력치 버프도 피해·보호막·지속시간을 올린다. 직업 소유·엘리트 하위 호환 판정은 내부 사용 조건으로 유지하되 발동 조건 문구에는 반복 노출하지 않는다.

마법사는 불·얼음·전기 속성 몬스터 처치 통계를 각각 5회 달성하면 화염구·빙결탄·뇌전구를 `autoAcquire`로 획득한다. 해당 스킬도 마법사 또는 마법사 계보 엘리트/서브 호환 조건을 유지한다.

## UI와 콘텐츠

루미나르 광장에서 `루미나르 전직소`로 이동해 전직관 세레나와 대화하면 전사·궁수·암살자·마법사·대장장이의 메인/서브 시험 10개를 받을 수 있다. 성직자 메인/서브 시험 2개는 광장과 직접 연결된 별도 안전 장소 `새벽교단 예배당`의 교리사제 엘리안만 제공하고 보고받는다. 정화 목표는 Lv.20 이하에서도 만날 수 있는 독 속성 적과 이후의 어둠·언데드 적을 포함한다. 어느 NPC에서 시작하든 진행 또는 보고 대기 중인 전직 시험이 하나 있으면 다른 전직 시험을 동시에 수락할 수 없다. `/직업(job, career)`은 현재 직업과 다음 해금, `/직업정보(ji)`는 직업 설명과 지급 스킬을 보여준다. `/상태창` 기본 정보에도 실제 메인/원래 계보와 서브 직업이 표시된다.

같은 전직소의 `계승관 아르덴`은 Lv.500 엘리트에게 메인 계보에 맞는 3차 시험 하나만 제시한다. `/직업`, `/상태창`, 관리자 플레이어 상세는 원래 메인·서브·엘리트와 현재 3차를 함께 표시한다. 3차 전용 아트 제작 전에는 원래 메인 계보의 128×128 직업/스킬 아이콘을 명시적 fallback으로 재사용한다.

대장장이는 `career:blacksmith` 정식 1차 직업이며 전직관 세레나에게 다른 직업과 동일하게 선택할 수 있다. 메인 시험은 광맥 5개, 서브 시험은 광맥 10개를 파괴하며 메인 전직 보상으로 철 곡괭이를 받는다. 전직 시 `야전 수리`도 획득하며 `/수리 <인벤토리 번호|장착칸>`로 정신력 20을 사용해 스킬 레벨에 따라 최대 내구도의 30~70%를 복구한다. 은맥 광부 보급소의 로안이 제공하는 `불꽃 없는 제련법`도 기존 별도 진입 경로로 유지된다. 메인이 비어 있으면 Lv.20부터 메인으로, 다른 메인이 이미 있으면 Lv.50부터 서브로 전직하며 두 슬롯이 모두 차 있으면 수락할 수 없다. 구형 `profession:blacksmith` 플래그는 로그인 시 기존 직업을 덮어쓰지 않고 빈 슬롯으로 이전하기 위한 숨은 호환 데이터로만 남는다. 별도 Prisma migration은 필요 없다.

대장장이 1차 권장 배분은 감각:체력:근력:정신력 `4:3:2:1`이다. Lv.200 대장장이 메인은 감각 4를 유지하면서 전사·궁수 서브는 근력 3, 암살자 서브는 민첩 3, 마법사 서브는 정신력 3을 배분하는 별도 진단 기준을 사용한다. 감각은 일반 치명타 능력과 함께 `제련 정밀도`를 1당 0.15% 올리고, 결 파쇄와 대장장이 성장·엘리트 기술은 현재 제련 정밀도로 주 피해·보호막 계수를 추가 증폭한다. 정신력은 1당 마법 저항력 0.5도 제공해 마법 방어 성장 경로가 된다. 메인 대장장이는 최대 생명력·방어·치명타 확률을, 서브 대장장이는 최대 생명력·방어를 보강한다.

근력은 1포인트마다 공격력 +2에 더해 물리 관통력 +0.5와 최대 중량 +0.2kg을 제공한다. 물리 직업은 공격력만 올리는 단일 축이 아니라 방어가 높은 적을 상대하는 관통과 전리품·중장비 휴대 여유도 함께 성장한다.
