# 차원 균열·인스턴스 던전 기획

## 한 줄 정의

차원 균열은 상위차원의 대마녀 `다클레비스`가 루미나르 세계를 침식하며 만든 일시적 통로다. 플레이어는 10초 동안 열린 게이트로 자유롭게 합류하고, 닫힌 뒤에는 제한시간 안에 균열의 지배자를 쓰러뜨려 귀환 균열을 열어야 한다.

기존 필드 던전이 월드의 지리·유적을 탐험하는 상시 장소라면, 차원 균열은 참가자만 공유하는 일회성 런타임 공간과 실패 가능한 원정이다.

## 세계관

### 다클레비스

다클레비스는 루미나르 세계보다 높은 차원에 존재하는 대마녀이며, 현재 장기 성장선의 Lv.10000 최종 보스다. 그녀는 직접 강림하지 않고 낮은 차원에 자신의 시선과 저주를 투사한다. 루미나르 곳곳의 균열은 이 투사가 현실의 약한 경계를 찢어 만든 상처다.

필드의 일반 몬스터는 본래 루미나르에서 자연 발생한 종만이 아니다. 균열 너머 원형 개체가 낮은 차원에 맞게 약화·변질되거나, 그 영향에 노출된 토착 생물이 닮은 형태로 변한 경우도 포함한다. 따라서 인스턴스 던전에서는 익숙한 계통의 몬스터가 더 완전하고 위협적인 형태로 등장할 수 있다.

다클레비스의 목적과 상위차원의 구체적인 질서는 초반에 확정적으로 설명하지 않는다. 플레이어는 균열의 반복, 마녀의 주시, 군주의 인장을 통해 침식의 주체가 있다는 사실부터 단계적으로 알아낸다.

### 지옥문의 재해석

승천 변경의 봉인 제단과 군주의 인장은 차원 균열을 억제하기 위해 남겨진 고대 장치다. 지금까지 `지옥문`이라 불린 것은 실제 지옥 한 곳으로 통하는 문이 아니라, 루미나르 밖의 적대적인 상위차원으로 좌표를 고정하는 금단의 의식이다.

후대 사람들은 문 너머에서 흘러나온 재앙을 모두 지옥이라 불렀다. Lv.1000 이후 플레이어는 인장과 제단을 역으로 이용해 다클레비스의 차원으로 향하는 첫 원정을 시작한다.

### Lv.1000과 초월

`기원종언체 아르케`는 다클레비스의 부하가 아니라, 세계의 시작과 끝이 만나는 경계를 지키는 존재다. 아르케 처치 뒤 사라지지 않은 `기원종언의 잔재` NPC가 나타나 다음 사실을 전한다.

1. 루미나르의 반복된 멸망과 변이는 외부 차원의 침식과 관련되어 있다.
2. 현재 육체로는 세계 경계를 넘어도 존재를 유지할 수 없다.
3. 한 생의 힘을 영혼의 격으로 압축하는 `초월`이 필요하다.

플레이어가 초월을 선택하면 초월 단계와 영구 보상을 얻고 Lv.1로 환생한다. 현재 확정된 환생 원칙은 다음과 같다.

- 초월 단계와 초월 보너스는 환생 뒤에도 유지한다.
- 현재 레벨·경험치와 습득 스킬은 신규 캐릭터의 초기 상태로 되돌린다.
- 귀속 아티팩트 `초월자의 여정`은 Lv.1000 미만의 최종 경험치 획득량을 10배로 만든다.
- 초월 보너스 스탯과 전용 패시브는 초기화하지 않고 새 회차에도 적용한다.
- 최초 환생은 플레이어가 명시적으로 확인한 뒤에만 실행한다.
- 두 번째 성장에서 Lv.1000 도달 조건을 다시 만족하면 아르케 전투를 반복 강제하지 않는다.
- 기원종언의 잔재가 경계 통과 권한을 확인하고 Lv.1000 이후 원정 거점으로 보낸다.
- 초월은 단순한 수치 초기화가 아니라 상위차원에서 존재하기 위한 자격이다.

초월하지 않고 기존 육체로 계속 성장할 수도 있지만 Lv.1000부터 최종 경험치 효율이 20%로 감소하고 Lv.1500을 넘을 수 없다. 초월자는 환생 뒤 Lv.1000까지의 반복 구간만 10배로 단축하고, Lv.1000부터는 정상 경험치 배율로 상위차원 원정을 성장시킨다. 따라서 10배 아티팩트는 첫 회차를 생략하는 도구가 아니라 이미 증명한 성장 구간을 빠르게 재통과하는 권한이다.

| 지도·도감 | 방문 기록과 월드 지도에 포함 | 지도·방문 기록·관리자 정적 저장에서 제외 |

## 입장 수명주기

### 1. 게이트 개방

필드의 `불안정한 차원 균열`과 상호작용한 첫 플레이어가 새 원정을 생성한다. 게이트는 생성 시점부터 정확히 10초 동안 열린다.

- 파티 명단을 복사하거나 참가를 예약하지 않는다.
- 파티 여부와 관계없이 같은 게이트를 직접 선택한 플레이어만 들어간다.
- 같은 파티라도 들어오지 않은 플레이어는 자동 이동하지 않는다.
- 최대 수용 인원은 던전 정의가 소유하며 기본값은 5명이다.
- 이미 다른 균열에 참가 중이거나 사망·이동 중인 플레이어는 입장할 수 없다.

첫 입장자가 게이트를 연 뒤 다른 플레이어는 남은 개방시간을 확인하고 합류한다. 이 방식은 파티장의 명단 관리보다 현장 모집과 즉석 협동을 우선한다.

### 2. 게이트 폐쇄

10초가 지나면 필드 측 게이트가 닫히고 해당 원정에는 더 들어갈 수 없다. 참가자 명단은 이 시점에 결과적으로 확정되지만, 사전에 강제하지 않는다.

폐쇄 뒤 접속을 종료한 플레이어는 짧은 재접속 유예 동안 같은 Player 객체와 인스턴스 위치를 유지한다. 유예가 끝나 unload되면 이탈자로 처리하며 다시 참가할 수 없다.

### 3. 마녀의 주시

입장 즉시 모든 참가자에게 제거 불가 상태효과 `마녀의 주시`를 적용한다.

- 남은 지속시간이 곧 던전 전체 제한시간이다.
- 정화·보존·상태 제거 아이템과 일반 해제 효과로 제거할 수 없다.
- 인스턴스 안에서 접속이 잠시 끊겨도 실제 시간 기준으로 계속 흐른다.
- 정상 귀환이나 운영상 강제 종료에서는 저주를 발생시키지 않고 정리한다.
- 시간 만료로 제거될 때만 `마녀의 저주`로 전환한다.

던전 HUD를 별도로 만들기 전에는 상태효과 HUD의 남은 시간과 게이트 메시지를 제한시간의 권위 표시로 사용한다.

### 4. 마녀의 저주

`마녀의 주시`가 시간 만료되면 제거 불가 상태효과 `마녀의 저주`가 5초 동안 적용된다.

- 5초에 걸쳐 현재 최대 생명력 기준으로 생명력이 붕괴한다.
- 회복·방어·보호막·무적·속성 저항으로 생존할 수 없다.
- 마지막 순간에는 생명력을 0으로 확정해 일반 Player 사망 수명주기를 사용한다.
- 별도의 즉사·강제 사망 API를 만들지 않는다.
- 저주로 전원이 쓰러지면 원정이 종료되고 참가자는 인스턴스 밖으로 정리된다.

5초의 유예는 시간초과 사실을 명확히 보여주고, 이미 열린 귀환 균열이 있다면 마지막 탈출 선택을 허용하기 위한 연출 시간이다.

### 5. 성공과 귀환

보스가 쓰러지면 보스방에 `귀환 차원 균열`이 생성된다.

- 제한시간은 즉시 정지하지 않는다.
- 생존자는 귀환 균열과 직접 상호작용해야 안전하게 탈출한다.
- 탈출한 플레이어의 주시와 저주는 부작용 없이 제거한다.
- 원래 게이트가 열린 필드 장소로 되돌려 보낸다.
- 모든 생존자가 탈출하거나 남은 참가자가 모두 사망·이탈하면 인스턴스를 폐기한다.

보스 처치 순간 자동 귀환시키지 않는 이유는 전리품 확인, 쓰러진 동료의 상태 판단, 제한시간 속 탈출이라는 마지막 선택을 보존하기 위해서다.

## 실패와 정리

원정은 다음 조건 중 하나로 끝난다.

- 살아 있는 참가자가 한 명도 남지 않음
- 마녀의 주시가 끝나 모든 잔류 참가자가 저주로 사망함
- 참가자가 전부 정상 귀환 또는 이탈함
- 서버 운영상 인스턴스 강제 종료

개별 참가자가 먼저 사망해도 살아 있는 참가자가 남아 있으면 원정은 계속된다. 사망자는 게이트가 이미 닫혔다면 같은 원정에 재입장할 수 없다. 원정 종료 시 동적 Location, 남은 몬스터·투사체·바닥 아이템과 임시 진행 상태를 함께 폐기한다.

인스턴스 사망은 기본적으로 필드 지역의 경험치·골드 손실과 분리한다. 균열 자체가 실패 비용을 제공하므로, 필드의 적대 지역 사망 패널티까지 중복 적용하지 않는 방향을 기준으로 한다.

## 방 진행과 파티 기믹 원칙

인스턴스 몬스터는 필드 개체의 원형 또는 상위 개체다. 단순히 생명력과 공격력만 올리지 않고 한 플레이어가 모든 문제를 순서대로 처리하기 어렵게 만든다.

### 일반 방

- 현재 네 구역 구성은 돌격형 선봉, 정예 수문장, 상태이상 추적체를 4→5→6마리로 조합하고 마지막에 지배자 한 개체를 둔다.
- 방 몬스터는 생존 참가자에게 순환 배정된다. 혼자면 방의 모든 몬스터가 한 사람을 압박하고, 둘 이상이면 최초 전선이 여러 사람에게 분산된다.
- 돌격·보호·지원 개체가 동시에 등장해 대상 우선순위를 요구한다.
- 지원 개체가 다른 몬스터를 회복하거나 보호하되 스스로는 약하게 만든다.
- 한 개체를 오래 방치하면 다른 개체를 강화해 공격 대상을 나누게 한다.
- 방의 모든 필수 개체를 쓰러뜨려야 다음 연결이 열린다.
- 몬스터 수는 참가 인원에 따라 늘릴 수 있지만 기믹의 핵심 역할 수는 2~3개로 제한한다.

### 보스

- 현재 대상 한 명에게만 피해를 집중하는 패턴에 의존하지 않는다.
- 서로 다른 플레이어가 짧은 시간 안에 행동해야 해제되는 동조·균열 파훼를 사용한다.
- 한 명이 장치를 유지하는 동안 다른 사람이 공격하는 병렬 책임을 사용한다.
- 위협 중첩으로 대상 교대를 요구하되 도발 직업 하나만 정답이 되지 않게 한다.
- 붙잡힌 참가자를 다른 참가자가 구출할 수 있게 한다.
- 실패는 즉사 한 번보다 누적 붕괴, 보스 강화, 제한시간 손실로 먼저 표현한다.

솔로 입장은 허용할 수 있지만 솔로 완주를 보장하지 않는다. 인원수에 맞춰 기믹을 모두 한 사람용으로 축소하면 인스턴스의 존재 이유가 사라지므로, 일부 동시 책임은 최소 두 명을 기준으로 유지한다.

## 난이도와 성장 배치

균열은 발견 장소와 개방자의 성장 구간을 기준으로 템플릿을 선택한다. 필드 개체가 균열 원형의 열화판이라는 인상을 주기 위해 같은 생태 계통과 속성 모티프를 재사용하되 이름·패턴·초상은 구분한다.

## 초월·환생 후속 구현 명세

초월은 인스턴스 던전 기반과 분리해 구현한다. 후속 변경은 다음 순서와 경계를 따른다.

1. `기원종언의 잔재` NPC와 아르케 최초 처치 flag, 다클레비스 정보 공개.
2. 되돌릴 수 없는 선택을 재확인한 뒤 레벨·경험치·습득 스킬을 초기화하는 원자적 환생 처리.
3. 귀속 아티팩트 `초월자의 여정`, 보너스 스탯, 전용 패시브와 초월 단계 영속화.
4. 비초월 Lv.1000 이상 경험치 ×0.2, 비초월 Lv.1500 상한, 초월자 Lv.1000 미만 경험치 ×10의 단일 경험치 배율 경계.
5. Lv.1000 재도달 판정과 아르케 전투 스킵, 상위차원 원정 거점 이동 권한.
6. 초기화 대상 중 인벤토리·골드·직업·퀘스트·도감·칭호·지도 방문의 세부 정책과 반복 초월 상한은 환생 저장 경계를 구현하기 전에 확정한다.

## 런타임 소유 경계

인스턴스 진행은 DB에 저장하지 않는 서버 메모리 상태다.

- 인스턴스 manager가 원정, 게이트, 참가자, 원래 위치와 동적 Location ID를 단독 소유한다.
- 동적 Location은 정적 장소 registry와 분리하며 지도·도감·관리자 JSON 저장에 포함하지 않는다.
- 외부 기능은 원정 Map이나 참가자 Set을 직접 읽지 않고 조회·입장·탈출 API를 사용한다.
- Player 위치 setter는 동적 Location을 영구 방문 flag로 기록하지 않는다.
- 서버 재시작 또는 런타임 소실 뒤 동적 위치 ID를 복원할 수 없으면 기존 안전 부활 위치로 보낸다.
- 주시·저주는 `WALL_CLOCK`으로 저장하지 않고 원정과 함께 사라지는 전투 세션 효과로 둔다.

## 현재 구현 범위

이번 기반 구현은 다음을 포함한다.

- 정적 월드와 분리된 동적 Location 등록·조회·해제
- Lv.10~960 권장 구간의 19개 균열, 76종 원형 개체, 균열별 네 개 전투 구역
- 9개 기존 성장 거점과 10개 승천 권역 쉼터의 필드 게이트
- 필드 게이트 첫 상호작용 시 원정 생성
- 명단 강제 없는 10초 합류 창과 최대 5명 제한
- 입장 시 마녀의 주시, 만료 시 5초 마녀의 저주
- 방의 필수 몬스터를 모두 처치한 뒤 다음 방 이동
- 보스 처치 시 귀환 균열 생성
- 귀환 상호작용, 전멸·시간초과·이탈 정리
- 지도 방문·도감·정적 관리자 저장에서 인스턴스 제외
- 일반 방 몬스터의 참가자 순환 교전과 솔로 집중 압박
- 공용 수명주기·콘텐츠 배치·게이트 참조 회귀 테스트

초월/환생, Lv.1000 잔재 NPC, Lv.1000~10000 상위차원 권역과 다클레비스 본체전은 이 기반 위에 올리는 후속 콘텐츠다.
