# SEED WALK

GAME BOX의 두 번째 게임으로, 시드 기반 결정론 2D 탑뷰 멀티플레이 산책 게임이다. 운영 경로는 `http://gamebox.mcv.kr/games/seed-walk/`이며 로그인한 계정은 별도 회원가입·캐릭터 정보 입력 없이 포털 닉네임으로 참가한다. DaclionOnline 도메인에서 같은 경로에 접속하면 포털 도메인으로 보낸다.

## 플레이 흐름

포털 카드 → 시드 입력(기본 gamebox) → GAME BOX 세션 검증 → 시드별 월드 참가 → Phaser 화면에서 WASD/방향키·모바일 왼쪽 아날로그 조이스틱으로 이동한다. 같은 시드의 접속자는 같은 맵에서 만난다. 맵 주소의 seed query를 공유하면 같은 맵에 들어갈 수 있다. 캐릭터는 계정별 색이 있는 원형이며 눈·발밑 그림자·닉네임을 표시한다. 자신은 흰 테두리와 `(나)`로 구분하고 카메라가 따라간다.

## 결정론과 서버 권위

`shared/seedWalk.ts`의 map version 1이 NFC 정규화·공백 제거 후 최대 48자의 seed를 받아 64×64, 32px 타일 지형을 만든다. 안정적인 32비트 문자열 hash로 풀밭·연못·바위를 배치하고 산책로와 중앙 안전 지점을 보장한다. 이동 가능한 모든 타일은 중앙과 연결된다. 지형 변경은 version을 올리고 fixture 테스트를 갱신해야 한다.

서버는 기존 20Hz 루프에서 고정 50ms 이동을 계산한다. 클라이언트가 보낼 수 있는 것은 증가 seq와 [-1,1] 범위의 유한 방향축뿐이다. 계정·이름·최종 좌표는 클라이언트 입력을 신뢰하지 않는다. 이동 속도는 초당 180, 반경 10이며 대각선 속도를 정규화하고 연못·바위·가장자리 충돌을 서버가 처리한다. 플레이어끼리 충돌하지 않는다. 클라이언트는 서버 좌표를 보간하며 아직 이동 예측은 적용하지 않는다.

## 수명과 제한

최대 16개의 활성 시드, 각 32명이다. 같은 계정의 같은 맵 탭은 한 캐릭터를 공유하고 서로 다른 시드에 동시 접속할 수 없다. 키 입력 heartbeat가 300ms 끊기면 정지하며 blur/hidden/키 해제도 즉시 정지 입력을 보낸다. 연결 해제·맵 나가기·포털 복귀·로그아웃·세션 폐기 때 참가를 제거하고 빈 맵을 폐기한다.

맵 seed/version으로 재생성되는 지형과 접속 중 이동만 있으므로 DB 영속 상태·dirty flush·추가 GameProfile row는 없다. 재접속/재시작 후 위치는 중앙에서 시작한다. 다른 게임의 Player/인벤토리/전투 상태를 조회하거나 생성하지 않는다.

## 구현 경계

- 클라이언트: `client/src/games/seed-walk/`와 포털 카드.
- 공유: `shared/seedWalk.ts`의 enum·map·physics·DTO와 `shared/types.ts` 이벤트 map.
- 서버 상태: `server/src/models/seed-walk/SeedWalkWorld.ts`.
- 서버 연결: `server/src/modules/seed-walk/seedWalk.ts`와 기존 게임 루프의 `updateSeedWalk(dt)`.

검증은 고정 v1 맵 fixture, 시드 정규화·타일 연결성, 속도·충돌·오래된 입력·타인 연결 차단·입력 만료·탭 정리·용량 제한, 실제 두 클라이언트의 입장·상대 이동·퇴장을 포함한다.

초원 색상은 `seedWalkGrassNoise/seedWalkGrassColor`의 시드 기반 3-octave Perlin 노이즈로 위치별 밝기를 은은하게 바꾼다. 시드가 같으면 색 분포도 같고, 이 시각 표현은 기존 지형/충돌 v1 fixture를 변경하지 않는다.

모바일 조이스틱은 왼쪽 하단에 표시하고 15% dead zone 뒤 기울기만큼 이동 속도를 조절한다. 서버는 방향 벡터의 최대 길이를 1로 제한하며, 손 떼기·pointer 취소·포커스 이탈에서 즉시 정지한다. PC는 WASD/방향키를 유지한다.
