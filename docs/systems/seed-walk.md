# SEED WALK

GAME BOX의 두 번째 게임으로, 시드 기반 결정론 2D 탑뷰 멀티플레이 산책 게임이다. 운영 경로는 `http://gamebox.mcv.kr/games/seed-walk/`이며 로그인한 계정은 별도 회원가입·캐릭터 정보 입력 없이 포털 닉네임으로 참가한다. DaclionOnline 도메인에서 같은 경로에 접속하면 포털 도메인으로 보낸다.

## 플레이 흐름

포털 카드 → 게임 시작 → GAME BOX 세션 검증 → 공용 월드 참가 → Phaser 화면에서 WASD/방향키·모바일 왼쪽 아날로그 조이스틱으로 이동한다. 모든 플레이어는 서버가 고정한 `gamebox` 맵에서 만난다. 클라이언트 요청과 URL의 seed query는 맵 선택에 영향을 주지 않는다. 캐릭터는 계정별 색이 있는 원형이며 눈·발밑 그림자·닉네임을 표시한다. 자신은 흰 테두리와 `(나)`로 구분하고 카메라가 따라간다.

## 결정론과 서버 권위

`shared/seedWalk.ts`의 map version 2는 풀밭만 있는 열린 초원이다. 연못·길·바위·가장자리 충돌을 제거했다. 좌표가 음수이거나 기존 64×64 영역을 넘어가도 이동하며 카메라는 제한 없이 플레이어를 따라간다. 클라이언트는 보이는 영역과 여유 타일만 시드 기반 Perlin 색/풀잎으로 그려 세계 전체 텍스처를 만들지 않는다.

서버는 기존 20Hz 루프에서 고정 50ms 이동을 계산한다. 클라이언트가 보낼 수 있는 것은 증가 seq와 [-1,1] 범위의 유한 방향축뿐이다. 계정·이름·최종 좌표는 클라이언트 입력을 신뢰하지 않는다. 이동 속도는 초당 180, 반경 10이며 대각선 속도를 정규화하며 지형 충돌은 없다. 플레이어끼리 충돌하지 않는다. 클라이언트는 서버 좌표를 보간하며 아직 이동 예측은 적용하지 않는다.

## 수명과 제한

공용 맵은 최대 32명이며 가득 차면 입장을 거절한다. 별도 방으로 나누지 않고 같은 계정의 여러 탭은 한 캐릭터를 공유한다. 키 입력 heartbeat가 300ms 끊기면 정지하며 blur/hidden/키 해제도 즉시 정지 입력을 보낸다. 연결 해제·맵 나가기·포털 복귀·로그아웃·세션 폐기 때 참가를 제거하고 빈 맵을 폐기한다.

맵 seed/version으로 재생성되는 지형과 접속 중 이동만 있으므로 DB 영속 상태·dirty flush·추가 GameProfile row는 없다. 재접속/재시작 후 위치는 중앙에서 시작한다. 다른 게임의 Player/인벤토리/전투 상태를 조회하거나 생성하지 않는다.

## 구현 경계

- 클라이언트: `client/src/games/seed-walk/`와 포털 카드.
- 공유: `shared/seedWalk.ts`의 enum·map·physics·DTO와 `shared/types.ts` 이벤트 map.
- 서버 상태: `server/src/models/seed-walk/SeedWalkWorld.ts`.
- 서버 연결: `server/src/modules/seed-walk/seedWalk.ts`와 기존 게임 루프의 `updateSeedWalk(dt)`.

검증은 고정 v2 초원 fixture, 시드 정규화·타일 연결성, 속도·충돌·오래된 입력·타인 연결 차단·입력 만료·탭 정리·용량 제한, 실제 두 클라이언트의 입장·상대 이동·퇴장을 포함한다.

초원 색상은 `seedWalkGrassNoise/seedWalkGrassColor`의 시드 기반 3-octave Perlin 노이즈로 위치별 밝기를 은은하게 바꾼다. 시드가 같으면 색 분포도 같고, 색상은 월드 좌표로 결정해 화면 밖과 음수 좌표에서도 일관된다.

모바일 조이스틱은 왼쪽 하단에 표시하고 15% dead zone 뒤 기울기만큼 이동 속도를 조절한다. 서버는 방향 벡터의 최대 길이를 1로 제한하며, 손 떼기·pointer 취소·포커스 이탈에서 즉시 정지한다. PC는 WASD/방향키를 유지한다.

## 말풍선 채팅

Enter 또는 채팅 버튼으로 화면 중앙보다 조금 아래(맵 영역 62%)에 입력 폼을 연다. 입력 중 이동은 정지하고 Enter로 전송·닫기, Escape로 취소한다. 한국어 IME 조합 Enter는 전송하지 않는다. 모바일은 채팅 버튼과 보내기를 사용한다.

`seedWalkChat(text)`는 참가한 인증 계정의 연결만 허용하고 120 UTF-16자 이하, 제어 문자 공백 치환·trim 후 비어 있지 않은 메시지를 받는다. 계정당 3초 3회 제한으로 탭 우회를 막는다. `SeedWalkWorld.say`는 캐릭터당 최신 말풍선 하나를 소유하고 기존 20Hz update에서 5초 후 제거한다. 말풍선은 복사된 player snapshot의 선택적 `bubble: { text }`로 전송되며 재접속/새 입장 시에도 남은 시간 동안 보인다. 서버 시계를 클라이언트 시계와 비교하지 않는다.

채팅은 캐릭터 위 DOM 말풍선으로만 표시하고 Phaser 카메라 위치에 맞춰 투영한다. HTML로 해석하지 않는다. 채팅 로그·DB 저장·오프라인 기록은 없다.

SEED WALK 플레이 중에는 헤더·툴바·하단 안내·방향/좌표 라벨 없이 canvas가 전체 viewport를 채운다. Esc 또는 아이콘 메뉴 버튼이 native modal dialog를 열며 계속하기·테마·맵 나가기·포털 이동과 접속 인원을 제공한다. 메뉴 중 자신의 입력만 정지하고 멀티플레이 월드는 계속된다. Esc는 채팅이 열려 있으면 채팅만 취소하고, 그 외 메뉴를 토글한다. dialog의 기본 focus trap을 사용한다.
