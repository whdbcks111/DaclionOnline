# 제작법·제작 시스템

제작법은 `models/Crafting.ts`의 정적 레지스트리에 등록하며, 제작법 발견 상태는 기존 `PlayerProgress` flag로 저장한다. 재료 판정과 교환은 제작 코드가 Inventory raw 배열을 읽지 않고 `Inventory.selectItems/replaceSelectedItems`를 사용한다.

```text
data/crafting.ts::defineCraftingRecipe
  ↓
Player.update → updateCraftingRecipeDiscovery → PlayerProgress flag
  ↓
/제작법목록 또는 /제작 <이름> [개수]
  ↓
Inventory.selectItems → 제작 대기 → factory → replaceSelectedItems
```

## 제작법 정의

`CraftingRecipeData` 필드는 다음과 같다.

| 필드 | 의미 |
| --- | --- |
| `id` | `namespace:path` 형식의 영구 ID |
| `resultItemDataId` | 일반적인 결과 아이템 ID. `name`을 생략하면 이 아이템의 이름을 제작법 이름으로 쓴다. |
| `name`, `aliases`, `description` | 명령 검색과 UI 표시 정보 |
| `ingredients` | `CraftingRecipeIngredient` 배열. label, 필요 수량, `Item` predicate를 가진다. |
| `craftTime` | 1개 제작에 걸리는 초. 여러 개는 `craftTime × 개수`만큼 걸린다. |
| `create` | 플레이어, 제작법, 개수, 실제 선택된 재료를 받아 `ItemSnapshot` 결과를 만드는 factory |
| `discoveryCondition` | 선택. 생략하면 1회분 재료를 모두 소지했을 때 발견한다. 정의하면 기본 조건을 완전히 대체한다. |
| `tags` | 제작법 분류와 후속 조건에 쓸 태그 |

정의 ID로만 필터링할 때는 `CraftingRecipeIngredient.item(itemDataId, count)`를 쓴다. 아이템 상태를 보는 재료는 직접 predicate를 정의한다.

```ts
new CraftingRecipeIngredient(
    '내구도 50% 이상의 검',
    1,
    item => item.category === '검'
        && item.durability !== null
        && item.baseDurability !== null
        && item.durability >= item.baseDurability * 0.5,
)
```

factory의 `ingredients` 안에는 predicate에 실제로 선택된 `Item`과 수량이 들어온다. 따라서 수리, 합성, 메타데이터 승계처럼 재료 인스턴스의 상태에 따라 결과가 달라지는 제작을 만들 수 있다.

## 재료 선택과 소비

`Inventory.selectItems()`는 최대 유량으로 여러 predicate와 아이템 수량을 매칭한다. 하나의 아이템이 여러 재료 조건에 맞더라도 같은 수량을 중복 계산하지 않으며, 가능한 전체 배정이 있으면 찾는다.

`Inventory.canReplaceSelectedItems()`와 `replaceSelectedItems()`는 선택 수량, 결과 snapshot, 제작 후 총 무게를 같은 규칙으로 검증한다. 전자는 재료를 소비하지 않는 사전 검사이고 후자는 검증 뒤 재료 제거와 결과 추가를 하나의 도메인 작업으로 처리한다. 제작 대기 중에 재료가 달라지면 완료 시점에 다시 선택하고, 조건을 충족하지 못하면 소비 없이 실패한다.

## 발견·실행 수명주기

- 발견 상태는 `crafting:recipe/{namespace}/{path}` Progress flag로 저장되며 플레이어의 주기 저장, unload, 종료 flush에 포함된다.
- `Player.update()`가 0.5초 마다 미발견 제작법 조건을 검사하며, 발견 시 채팅과 notification을 보낸다.
- 한 플레이어는 동시에 하나의 제작만 진행한다. 접속 종료나 사망 시 취소된다.
- 재료는 시작 시 잠그거나 소비하지 않고 완료 시 교환한다. 따라서 중도 취소로 재료가 유실되지 않는다.
- 제작법 발견과 제작 완료는 각각 `crafting:recipe_discovered`, `crafting:item_crafted` GameEvent를 발행한다.

## 명령어와 현재 콘텐츠

- `/제작법목록`: 발견한 제작법의 재료, 1개당 시간, 현재 제작 가능 여부와 제작 버튼을 표시한다.
- `/제작 <제작법이름> [개수]`: 마지막 token이 숫자면 1~99의 제작 개수로 해석하고 생략 시 1개를 만든다.
- `basic:iron_pickaxe`는 철광석 3개와 돌 2개로 4초에 철 곡괭이 1개를 만든다.
- 황혼왕릉의 5개 자동 발견 제작법은 지역 소재와 기존 제련 소재를 함께 사용해 묘지기 향약, 맹세철 장검, 진혼 시위, 애도목 지팡이, 묘문 수호방패를 만든다. 상점 구매 외에도 사냥·제련·제작을 잇는 회수 경로다.
- 유리모래 사막의 6개 자동 발견 제작법은 지역 소재로 그늘 물통과 모래쐐기 장검·태양실 활·신기루 독아·태양유리 지팡이·태양거울 방패를 만든다. 재료 predicate는 공개 아이템 API와 데이터 ID를 사용하고 결과는 기존 마스터 아이템 factory로 생성한다.
- 서리잔향 설원·빙경궁의 7개 자동 발견 제작법은 눈솔이끼·상고 수정·경철·빙실·극광·빙결 핵으로 빙결 저항/재생 소모품과 빙맥 절단검·빙실 연궁·경빙 송곳니·극광분광 지팡이·빙경 성벽방패를 만든다. 상점과 보스 드롭만이 아니라 사냥·채굴·제작을 통한 회수 경로를 함께 제공한다.
- 안개파도 해안·침몰왕도의 8개 자동 발견 제작법은 해무 소금·흑산호·해무비늘·조류진주·침수 군단 휘장·심해철·청해초 수지·해수룡 골편으로 생존 소모품 3종과 파식 조류검·해무 조류궁·흑산호 침·심해진주 지팡이·침몰제독 방패를 만든다. 해안 채집, 두 보스 드롭, 항구 상점과 제작이 같은 지역 소재를 순환한다.
- 카이로스 공방도시의 9개 자동 발견 제작법은 시간강 파편·기억 톱니·광자 렌즈·공허 용수철·논리핵·역설 실·자동인형 장갑판·균열 수정을 사용한다. 태엽 작업식·위상 촉진제·논리회로 영약·시간봉합 연고와 역설절단검·광자연사궁·공허태엽 단검·논리핵 지팡이·인과율 방패를 만들며, 중계소 상점과 사냥·채굴·유물함 보상이 같은 소재 순환을 이룬다.
- 아셴바흐 심연의 8개 자동 발견 제작법은 잿빛 힘줄·흑염 잔재·공허뿔·저주뼈·밤쇠·재왕 인장·심연가죽·애도의 눈을 사용한다. 생존 소모품 3종과 재가름 장검·공허뿔 장궁·황혼송곳·흑염각 지팡이·재성벽 방패를 만들며, 휴게소 상점·밤쇠 채굴·보스 사냥·봉인 유산고가 같은 소재 순환을 이룬다.
- 벨카인 요새의 7개 자동 발견 제작법은 무광은·왕관유리·공허비단·기아덩굴·별먹·섭정 인장을 사용한다. 생존 소모품 2종과 무광은 파성검·왕관현 장궁·공허비단 침·무성좌 지팡이·섭정의 무광방패를 만들며, 귀환표식 상점·무광은 채굴·보스 사냥·비밀금고가 같은 소재 순환을 이룬다.
- 루나리스 해구의 7개 자동 발견 제작법은 월염수·월식비늘·침은·밤진주·해구섬유·조류인장을 사용한다. 생존 소모품 2종과 침은 파도검·월조류 장궁·밤진주 잠행도·월식 예언봉·백야 조류방패를 만들며, 관측선 상점·침은 채굴·보스 사냥·침수보물고가 같은 소재 순환을 이룬다.
- 카미하라 숲의 7개 자동 발견 제작법은 천근수피·태초수액·기억호박·망각포자·심장씨앗·근골철을 사용한다. 생존 소모품 2종과 근골철 파근도·심장현 대궁·기억호박 송곳니·기원심장 지팡이·천개 심장방패를 만들며, 길잡이 둥지 상점·근골철 채굴·보스 사냥·기억호박 유물고가 같은 소재 순환을 이룬다.

## 연금술 조제

`마법사 메인 → 성직자 서브`의 ordered 엘리트 직업 `연금술사`만 `/연금술 <1~3> <음용|투척> <재료명x수량, ...>`으로 조제한다. `/연금술법`은 일반 제작법과 분리된 등록 연금 조합표에서 병당 재료·난이도·현재 보유량을 보여준다. 명령 파서는 ItemData 배열을 훑지 않고 `Alchemy`가 공개한 reagent registry만 사용한다.

재료와 정제수의 원자 소비가 성공한 첫 `ready`에서 투입한 reagent마다 `PlayerProgress` 영구 실험 flag를 기록한다. 시작 전 선검사·idle 취소에는 기록하지 않으며, 이후 추적 성공·실패·연결 종료와 관계없이 기록을 유지한다. 연금술사 전용 `/연금재료정보 <재료명>`은 실험한 재료만 조회하며 감각 200에서 이름·분류·설명, 300에서 연금 성질, 400에서 수량을 숨긴 호환 조합·결과·짝재료, 500에서 병당 정확 수량·난이도·등록 기본 효과를 단계적으로 공개한다. 자동완성은 실험 기록이 있는 재료만 제공하며, 직접 입력한 미실험 재료에는 기록이 없다고 답한다.

- 기존 14개 지역 재료를 생명·정신·재생·전투·비전·신속·정화·보존·독성·촉매 성질에 명시적으로 연결한다.
- 생명력 회복, 정신력 회복, 재생, 물리 전투 강화, 마법 강화, 신속, 해독, 보존, 독성의 9개 조합식을 제공한다.
- 한 번에 1~3병을 만들 수 있으며 결과 한 병마다 일반 상점의 `정제수 물병` 하나와 모든 조합 재료의 같은 배수가 정확히 필요하다. 재료 종류와 총수량이 조합식에서 하나라도 다르면 미확인 조합이다.
- 명령 입력 시에는 `Inventory.selectItems()`로 재료·물병 보유 여부만 사전 검사한다. 움직이는 목표 원을 처음 눌러 `miniGameReady`가 승인되는 순간 같은 요구량을 다시 선택하고 `replaceSelectedItems()`로 한 번만 원자 소비한다. 그 전에 재료 구성이 바뀌면 조제를 취소하고 아무것도 소비하지 않지만, 시작이 승인된 뒤에는 추적 실패·시간 초과·연결 종료에도 투입 비용을 유지한다. 성공 결과는 `addItemSnapshot()`으로 지급하고 중량이 가득 찼다면 현재 위치 바닥에 놓는다.

조제 미니게임 `alchemy_tracking`은 조합식·재료 hash로 seed, 궤도·팔자·네잎·나선·번개 중 경로, 등속·맥동·급가속, 방향 반전 일정을 결정한다. 위에서 본 가마솥의 액체 반경 안에 모바일 터치도 따라가기 쉬운 4.5~6 반경의 목표 원과 전체 경로를 표시한다. 목표 원 내부를 처음 누를 때만 focused socket이 `miniGameReady`를 보내 실행 시계를 시작하며, 보드의 다른 곳을 누르는 것은 시작으로 인정하지 않는다. 시작 전 30초 idle 만료는 취소라 재료를 쓰지 않고, 시작 후 게이지 0·실행 시간 만료·proof 실패는 조제 실패로 재료와 물병을 소모한다.

클라이언트는 최초 down 표본을 후속 move/up으로 덮지 않는 20ms 절대 pointer trace와 100ms 목표·pointer·게이지 궤적 proof를 제출한다. 서버는 자신이 발급한 config/seed로 이를 느슨하게 재생하며 최초 표본이 20ms 이내·dragging·시작 목표 원 내부인지 검사한다. 서버 시계보다 앞선 client 경과는 ready 전달 흔들림 500ms까지만 허용하고, 정상 완료 뒤 늦은 도착은 5초까지 허용해 공개 simulator로 미래 궤적을 만들어 조기 제출하는 것을 막는다. 성공 시 서버 재생의 목표 유지율과 원 중심 근접도를 합친 정확도에 감각의 상한형 보너스를 더해 탁한·안정된·정제된·우수한·명인의 품질을 정한다. 품질은 효율, 지속시간, 투척 최대 대상 수 2~5명을 함께 높인다.

유효한 조합을 성공하면 정상 조제약, 미확인 조합을 성공하면 해가 없는 약한 회복용 실패약을 얻는다. 추적 실패에는 결과물이 없다. 완성품은 전달 방식·품질·정확도·효과를 인스턴스 metadata로 저장하므로 같은 마스터 ID라도 다른 품질은 잘못 합쳐지지 않는다. 음용형은 자신에게 적용한다. 투척형은 서버가 현재 대상·장소·파티를 다시 검사해 회복·강화약은 같은 장소의 자신과 생존 파티원, 독성약은 현재 공격 가능한 몬스터 중심으로만 추상 범위 적용하며 다른 파티나 임의 원격 대상에는 적용하지 않는다.

## 조합형 단조 장비 기반

`/단조 <형태> <제련 재료> [성능 상한]`의 마지막 정수는 선택 사항이다. 상한이 있으면 제작자 레벨 기반 성장치와 최종 장비 레벨을 함께 제한하며, 완성품 착용 레벨은 최종 성능 레벨의 `ceil(80%)`다. 상한을 생략하면 제작자의 전체 성장치를 사용한다.

Lv.600~1000 전용 광산은 각 광맥에서 3%씩 희귀 원광 두 종을 제공한다. 두 희귀 원광의 합산 확률은 6%이며 일반 권역 소재가 나머지 94%를 차지한다. `ForgeMaterial.rawItemDataId`가 원광→제련 소재 관계의 단일 원본이며 `마력 제련`은 성철강·심연은·폭풍석영·생혈합금·공허오팔·성원석·기원프리즘·시류결정을 변환한다. 여덟 소재는 관통, 방어·정신력, 공격/투사체 속도, 생명력/재생, 치명타, 정신력 재생, 복합 관통, 이동/행동 속도의 서로 다른 단조 보너스를 가진다.

Lv.78 유리모래맥부터 Lv.482 소멸금 성좌맥까지 다섯 성장 광맥은 각각 3% 확률로 태양광핵·월빙광·시계청광·심조광·종성금강광을 제공한다. 제련 결과인 태양강·월빙은·시계청강·조류유리합금·종성금강은 관통, 마법 방어·정신력, 공격·투사체 속도, 마법력·정신력 재생, 물리·마법 복합 화력으로 단계적으로 성장한다.

고레벨 낚시터 전용 어종은 생선 요리 5종의 제작 재료다. 생선 자체도 바로 먹을 수 있지만 조리품은 3~4분의 더 강한 상태효과를 제공한다.

Lv.500 이전 다섯 낚시터의 전용 어종도 햇살가오리 꼬치·청해초 달대구 차우더·톱니비늘 전류전골·월식 돛새치 스테이크·마지막빛 산갈치 만찬으로 조리할 수 있다. 효과 레벨과 지속시간은 각 낚시터의 성장 구간에 맞춰 2~3분 범위로 상승한다.

기존 재료군에 수정 광맥에서 채굴하는 `마나 수정`과 마력 제련 결과인 `정제 마나 수정`을 추가한다. 원석은 먼저 `마력 제련`으로 정제해야 하며 `/단조 장검 마나 수정`, `/단조 장검 마나수정`, `/단조 장검 정제 마나 수정`을 모두 같은 재료 입력으로 해석한다. 마나 수정 단조품은 제작자 레벨·감각에 따라 마법력·최대 정신력·마법 관통력이 성장한다. 단검과 철갑화는 재료와 무관하게 완성품 레벨·정확도·제련 정밀도에 비례한 이동속도 고정 보정을 얻는다.

`Forging`은 일반 제작법과 달리 하나의 고정 마스터 아이템을 그대로 복제하지 않는다. 무기·도구 형태인 장검·도끼·단검·곡괭이와 방어구 형태인 방패·투구·흉갑·각반·철갑화 `ForgeForm`을 철·금·루비·에메랄드·다이아몬드·홍염강 `ForgeMaterial`과 조합하고, 리듬 단조 품질로 효율을 계산한다. 투구·흉갑·각반·철갑화는 각각 머리·몸·다리·발 슬롯에 장착되며 공격력 대신 방어력이 성장한다. 주 능력치는 형태의 기준 수치에 제작자 레벨 10 초과분, 감각 50 초과분, 제련 정밀도의 로그형 숙련 기여를 `craftsmanshipPower`로 환산한 뒤 형태·재료·정확도·성향을 곱한다. 제련 정밀도는 높은 구간일수록 효율이 완만해지지만 고정 상한에서 잘리지 않는다. Lv.350 이후 전투 무기는 권역 상점 장비의 성장 폭을 따라가는 후반 보정을 추가로 받고, 장검·도끼·단검은 장비 레벨 비례 방어 관통, 단검은 이동속도, 활대는 치명타율을 얻는다. 따라서 Lv.200·감각 1000·제련 정밀도 150%의 균형 잡힌 철 장검은 정확도 85%에서 약 480 공격력을 가지며, 같은 조건의 명품 다이아몬드 장검은 600 이상의 공격력으로 성장한다. 홍염강은 홍염산지의 화맥 광맥에서 캔 `화맥 광석`을 마력 제련해야 얻는 지역 전용 합금이며 불·금속 태그, 마법력과 치명타 피해 보너스를 가진다. 형태와 재료는 기본 공격/방어 수치·내구도·속성 태그를 결정한다. 서버 난수로 선택하는 단조 성향은 단순 수식어가 아니라 능력치 trade-off다. 예리함은 위력/내구도 대신 치명타, 중량형은 공격/이동속도 대신 위력/내구도, 정밀형은 위력 대신 관통/공격속도, 질긴 성향은 위력 대신 방어/내구도, 마도형은 물리 위력 대신 마법 능력, 불안정형은 내구도 대신 최고 위력을 얻는다. 방어구·곡괭이는 무기 전용 치명타 성향에서 제외된다. 이 성향과 별도로 16% 확률의 특이 각인이 발생한다. 과부하(속도↔위력), 파갑(위력↔관통), 필살(치명타율↔치명타 피해), 생명 결속(위력↔레벨 비례 생명력/방어), 마도 결속(위력↔레벨·감각 기반 마법력/관통) 중 하나이며 이름 앞 단어와 `forge.quirk` metadata에도 기록된다. 마도 결속의 마법력은 감각에 제곱근 곡선을 적용하고 최대 160으로 제한해 일반 무기의 희귀 보조 각인이 동급 전용 지팡이의 주 능력치를 무한히 넘어가지 않게 한다. 일반 제작품은 높은 확률로 `철 장검` 같은 재료+형태 이름을 사용하고, 성향이 있으면 `불안정한 철 장검`처럼 평범한 이름에도 표시된다. 나머지는 품질/성향이 고른 판타지 접두어 어휘군, 실제 재료명, 형태별 RPG 명칭 후보를 조합한다. 완벽한 품질은 형태 고유 접두어를 사용하므로 품질 100%의 다이아몬드 도끼는 `익스클리프 다이아몬드 액스`가 된다.

결과는 `forged_*` 형태별 마스터 템플릿을 사용하되 `customName`, `customDescription`, `maxDurability`, `instanceModifiers`, `forge` metadata delta와 재료 속성 영속 태그만 저장한다. 따라서 같은 아이템 데이터 ID여도 서로 다른 이름·내구도·능력치를 갖는다. 공격/방어 수치는 형태 기본값 × 재료 배율 × 리듬 효율 × 제작 숙련 배율로 계산한다. 제작 숙련은 레거시 단조의 감각 100 초과분 효율을 현재 수치 체계에 맞춰 완화한 값으로, 캐릭터 레벨·감각·제련 정밀도를 반영하며 레벨/감각/정밀도별 상한을 둔다. 내구도에는 숙련 배율 증가분의 40%만 반영한다. `Item` 공개 getter와 `Equipment`가 이 유효값을 사용하며 metadata 원본이나 장비 내부 row를 직접 읽지 않는다. 전용 아이콘 제작 전에는 각 형태의 기존 카테고리 아이콘을 fallback으로 사용한다.

대장장이의 원거리 병기는 완성품을 바로 단조하지 않고 단조와 제작을 잇는다. `마도 대장장이`는 레벨과 무관하게, 일반·구형 호환 대장장이는 Lv.200부터 `지팡이 틀` 형태를 단조한 뒤 `/지팡이부여 <인벤토리 번호>`로 정신력 120을 소모해 마력 회로를 연다. 완성 지팡이는 틀의 이름·재료 태그·품질·내구도·능력치를 유지하고 장비 레벨에 비례하는 마법 관통력·정신력 재생·투사체 가속을 더하며, 기존 지팡이와 같은 마법 투사체 평타를 사용한다. Lv.500 이후에는 같은 권역 상점 지팡이의 재생·관통 성장 폭을 따라가고 Lv.950 제작품도 최종 성장 상점 지팡이 이상의 정신력 재생을 유지한다.

`기계 장인`은 `활대`와 `화살촉 묶음`을 단조할 수 있다. Lv.200 이상 일반·구형 호환 대장장이는 활대 단조, 호환 섬유 2개를 쓰는 강화 활시위 제작, 단조 활대+활시위 조립도 사용할 수 있다. 화살촉 묶음 단조, 단단한 나무 막대기 2개를 쓰는 화살대 10개 제작, 화살촉 묶음+화살대 10개 조립은 계속 `정밀 병기 제작` 전용이다. 완성 활과 화살은 커스텀 이름·능력치·재료 속성을 유지하고, 탄약은 `wooden_arrow` 마스터 ID와 인스턴스 metadata delta를 사용하므로 기존 활 전부가 그대로 소비할 수 있으며 품질이 다른 화살끼리는 잘못 합쳐지지 않는다.

대장장이 직업 또는 호환 계보를 가진 플레이어가 감각 250을 달성하면 `장인의 명명`을 자동 획득한다. `/장비명명 <인벤토리 번호|장착칸> <새 이름>`은 대상의 `forge.creatorUserId`를 공개 도메인 API에서 검사하므로 본인이 직접 단조한 장비만 공백 포함 2~24자의 이름으로 바꿀 수 있다. 이름은 `customName` delta에 저장되어 해당 인스턴스에만 적용되고 Inventory/Equipment의 기존 dirty flush로 영속된다.

대장장이 메인 + 마법사 서브가 Lv.200에 `마도 대장장이`가 되면 `마법 부여`를 얻는다. `/마법부여 <인벤토리 번호|장착칸>`은 정신력 80을 쓰고 아직 마법이 없는 무기에 한 번만 효과를 각인한다. 후보는 화염·맹독·기절·빙결·실명뿐 아니라 비전 추가 피해, 생명 흡수, 정신력 환류, 충격 결계, 매 공격 약타/강타 변동, 추가 투사체, 대상 현재 생명력 비례 피해를 포함한다. `/마법부여효과`에서 전체 후보와 설명을 확인한다. 기존 property/material 태그와 forge material/trait/name signature가 후보 가중치를 만들고 종류·발동 확률·레벨·지속시간·위력은 서버 난수로 확정된다. 결과는 `enchantment`와 검증된 `attackEffects` metadata delta 및 해당 property 영속 태그로 저장된다. 근접과 아이템 투사체 기본 공격 모두 실제 피해가 들어간 뒤 같은 Item 공개 API를 호출하며, 기존 보스 무기의 고유 `attackEffects`도 마법 부여 뒤 보존된다.

대장장이 메인 + 전사 서브가 Lv.200에 `전투 대장장이`가 되면 `장비 강화`를 얻는다. `/장비강화 <인벤토리 번호|장착칸>`은 `철근미궁 지핵 수정실`의 `강화 수정맥`에서만 채굴되는 `지핵 강화석` 1개를 모든 유효한 시도마다 소모한다. 기존 `/무기강화` 입력도 별칭으로 유지한다. 긍정 능력치가 있는 무기와 방패·투구·흉갑·각반·신발 방어구를 최대 +15까지 강화할 수 있다. 매 단계는 장비가 원래 가진 모든 양수 고정 능력치와 1배를 넘는 유리한 배율의 5%를 추가하며 +5/+10/+15에는 5%를 더해 누적 보너스가 각각 30%/60%/90%가 된다. 따라서 공격력·마법력·방어력뿐 아니라 최대 생명력·관통·치명타·재생·속도 계열 부가 옵션도 장비 원본 수치에 비례해 함께 성장한다. +2부터 실패가 생기고 +7 도전부터 단계 하락, +9 도전부터 장비 파괴가 발생한다. `/강화확률`은 목표 단계별 성공·유지·하락·파괴 확률을 정확히 표시한다. `reinforcement` metadata에는 강화 단계만을 기준값으로 저장하고 실제 modifier는 장비 원본에서 계산하므로 과거 고정 수치 강화 기록도 같은 단계의 새 비례 공식으로 자동 환산된다. 하락 시 계산 단계만 함께 내려가며 단조 결과·장인의 명명·마법 부여는 유지된다.

대장장이는 루미나르 전직소의 전직관 세레나에게 다른 직업과 동일하게 선택할 수 있다. 메인 시험은 광맥 5개, 서브 시험은 광맥 10개를 파괴하며 메인 전직 시 철 곡괭이를 받는다. Lv.20부터 은맥 광부 보급소의 마도 대장장이 로안에게 받는 `불꽃 없는 제련법`도 별도 전직 경로로 유지된다. 어느 경로든 현재 사용할 수 있는 메인 또는 서브 직업 슬롯에 정식 1차 직업 `대장장이`가 배정되고 대장장이의 담금질·결 파쇄·마력 제련·금속 단조 스킬을 얻는다. 다른 메인 직업을 이미 선택했다면 서브 슬롯이 열리는 Lv.50까지 기다려야 하며, 두 슬롯이 모두 차 있으면 전직할 수 없다. 마력 제련은 별도 용광로·연료·대기열 없이 정신력을 사용해 인벤토리에서 가장 앞선 원광을 `2 + 스킬 레벨 + floor(제련 정밀도 × 10)`개씩 처리한다. 정제 소재는 대응 원광보다 무거워지지 않으며, 교환 뒤에도 인벤토리가 중량 초과라면 오류 대신 여유 공간이 필요하다고 발동 전에 안내한다.

`/단조 <형태> <재료>`는 메인/서브/계보 중 대장장이 직업을 보유하거나 `금속 단조` 스킬을 별도로 보유하면 사용할 수 있다. 필요한 제련 소재를 확인하고 `forge_rhythm` 세션을 시작하며, 실패하면 선택 소재가 파손되고 성공하면 서버가 검증한 0~1 score를 장비 생성기에 직접 전달한다. 재료 power와 형태별 소모량으로 난이도 1~10, 박자 수, 정박·엇박·반 박자 연타의 조합을 확정한다. 난이도 4 이상은 단계마다 2.5%p의 품질 보정을 제공하되 실제 정확도가 성공 기준을 넘어야 적용된다. 감각에서 계산된 `제련 정밀도`는 45%까지 일반/Perfect 타격 판정창을 그대로 넓히고, 그 이후에는 90% 보정에 점근하는 완만한 곡선으로 계속 성장한다. 결과 정확도를 직접 더하지 않으므로 실제 리듬 입력은 계속 필요하다. 클라이언트는 첫 입력 뒤 접근 cue와 망치 충격음을 합성하고 난이도·원 정확도·보정 품질을 분리해 표시한다. 서버가 허용하는 종료 패킷의 짧은 조기 도착 오차는 전체 시간이 끝난 것으로 정규화해 정확도를 충족한 단조가 미완료로 실패하지 않게 한다. 성공 결과는 소재와 완성품을 `Inventory.replaceSelectedItems()`로 한 번에 교환하고 단조 이벤트·경험치·완성품 정보를 보낸다.

대장장이 생산 행동은 몬스터 처치 없이도 캐릭터가 성장하도록 경험치를 준다. 마력 제련은 처리 원광 하나당 현재 레벨의 `maxExp × 0.25%`, 1회 최대 4%를 지급한다. 단조 완성품은 제작자 레벨·재료 격·정확도로 장비 레벨을 계산해 설명과 `forge.itemLevel`에 기록한다. 성공 경험치는 그 장비 레벨의 일반 동급 몬스터 한 마리 경험치(`장비 레벨 × 20`)를 기준으로 거친 56%, 양호 80%, 우수 96%, 명품 116%를 지급한다. 실패에는 경험치가 없다.

감정 화면은 같은 능력치에 여러 단조 성향·재료·강화 modifier가 겹쳐도 행을 반복하지 않는다. 고정 보정은 합산하고 비율 보정은 실제 적용 순서대로 곱한 뒤 `물리 관통력 +18 +6%`처럼 한 행으로 표시한다.
