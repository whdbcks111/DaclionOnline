월드는 라그나벨 성단 이후 Lv.500~1000의 세라핀 하늘묘지·네레이아 수정바다·미르엔 꿈서고·벨토르 번개대장간·루스카 붉은황야·루멘 흰그늘길·그라벨 붉은분지·아오이 고요숲·니힐 기록원·아르케 끝자락으로 이어진다. 각 권역은 안전 거점 1곳을 포함한 31개 장소의 외곽 순환로, 상·하층 회귀로, 갈라졌다 합쳐지는 나선 심층, 막다른 유물함·가짜 종착지와 hidden 봉인 제단을 가진다. 보스방은 다음 권역 진행 통로를 막지 않는 옆길에 놓인다. Lv.550부터 Lv.1000까지 보스가 50레벨 간격으로 배치되며 별도 SkillData·위협 AI·지역 환경 효과를 사용한다.

레거시의 히든 스킬로 지옥에 진입하던 경험은 `지옥문`을 제단 전용 열쇠로 재구성한다. 현재 승천 권역은 보스가 100% 드롭하는 군주 인장과 `resource:otherworld-gate` 제단 기반을 제공한다. 후속 지옥 권역에서는 숨은 스킬 보유, 지정 제단, 서버가 검증한 인장·퍼즐 Progress를 모두 만족해야 문이 열리며 일반 이동·자동이동·지도 공개만으로 우회할 수 없게 한다.

## 확장 우선순위

1. 다음 콘텐츠 확장 전에는 `BALANCE_PROFILE_LEVELS`의 공용 회귀 결과와 `balance:report -- 1000`의 최종 구간 결과를 먼저 확인한다.
2. 관리자 밸런스 명령·페이지와 `balance:report`의 동레벨 일반/보스 프로필에서 회피율·관통 후 방어·처치시간·평타 비중을 확인한다.
3. 1차 직업 Lv.75~180의 보스 DPS 최고/최저 편차는 1.65배, Lv.200 순서 있는 엘리트 조합은 1.95배를 넘기지 않고 강화 후 평타 피해 비중을 13% 이상 유지한다.
4. 아직 확정 전용 아트가 없는 아이템·스킬·1차 균열 확장 몬스터는 존재하는 카테고리 fallback을 사용하고 교체 TODO를 유지한다. 기존 월드와 승천 권역 몬스터는 데이터 ID별 전용 초상을 유지한다.

## 2026-08-08 사용자 건의 처리 순서

이번 묶음에서 즉시 검증 가능한 회귀·밸런스·소규모 콘텐츠는 먼저 반영했다. 감각 1당 제련 정밀도 +0.15% 표시는 기존 상태창/스탯분배 설명으로 확인했고, 성물 해방은 최대 생명력 계수와 엘리트 티어 보정이 적용된 현재 회귀를 유지한다. 저레벨 일반 몬스터 경험치 감쇠는 플레이어 레벨의 60% 미만에서만 시작해 50% 아래로 내려가지 않는 현재 제한을 유지하고 실제 사냥 분포를 운영 지표로 확인한다.

1. **즉시 반영:** 속성 간 스킬 연계 0.5초, 기존 기술의 최대 정신력 비례 비용 제거, 초월 귀환 배낭, 균열 로그아웃 이탈 위치 저장, 대용량 포션 매입, 메인 대장장이 단조 경험치, 단조 패턴 무작위화·난도 12, 신화어 요리 3종.
2. **성장 루프 1차 — 완료:** `/패시브수련`의 집중/무작위 선택과 KST 일일 300 EXP 상한을 낚시·요리 성공 이벤트에 연결했다. 도감의 기존 능력치 보상은 총량을 유지한 엔트리별 보상으로 이전하고, 분류 전체 관통력, 백금 무피격·맨손 채광·요리 10배 조건과 보스 타임어택 기록을 `CodexBook` 소유 경계에 추가했다.
3. **NPC 생활 루프 — 완료:** NPC별 0~100 호감도와 KST 하루 10 상한, 5단계 의뢰 보상 배율과 최대 답례를 `PlayerProgress` dirty 저장 경계로 추가했다. 현재 장소 NPC의 일일 제작품 3개 또는 직접 선택한 단조품 1개를 납품해 Gold·EXP·호감도를 받고, 누적 30회에 `마을의 해결사` 칭호를 얻는다.
4. **프로필·채팅 꾸미기 — 완료:** Lv.1000·2000·3000과 초월 조건으로 청람·자수정·오로라·초월자 프레임을 영구 해금하고 프로필 원형과 채팅 카드에 별도로 장착한다. 감정표현 6종은 서버가 안정 ID·보유권·Gold·레벨·초월 조건을 확인해 구조화 채팅 노드로 전송한다.

도감·호감도·프로필은 영속 형식과 소급 보상 정책이 필요한 대형 변경이므로 위 순서대로 각각 독립 패치와 마이그레이션·회귀 테스트를 완료한 뒤 공개한다.

## 검증 기준

- `server/src/data/world/world.test.ts`가 장소 양방향 연결, 오브젝트 ID, 권역 대표색, 상점·제작법·퀘스트·퍼즐·보물·보스 패턴을 권역 단위로 검증한다.
- `server/src/scripts/validateMasterData.ts`가 모든 참조와 명시된 fallback 아이콘 경로를 검증하며, `server/src/data/world/world.test.ts`가 기존 몬스터 전용 초상의 ID별 유일성과 균열 fallback을 포함한 모든 몬스터 초상의 64×64 RGBA 규격을 검증한다.
- `server/src/scripts/reportBalance.ts`가 공용 레벨 구간과 황혼왕릉부터 라그나벨 성단까지의 장비를 같은 직업/레벨 기준선에서 비교하고, 지역 전승 기술의 회피·관통·자원·쿨다운을 함께 출력한다.
- `server/src/models/progression/Balance.test.ts`가 6개 1차 직업과 순서 있는 엘리트 30조합의 보스 DPS 편차 1.65/1.95배, 강화 후 평타 피해 비중 13% 이상을 회귀 검증한다.
- 수량은 문서의 추정이 아니라 현재 마스터 데이터를 실제로 import한 런타임 레지스트리 수와 `locations.json` 길이로 갱신한다.
