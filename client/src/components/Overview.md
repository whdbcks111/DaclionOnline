# Components Overview

페이지에서 조합하는 공용 UI를 둔다.

- `Header`: 채널명과 접속 인원.
- `Drawer`: 프로필/닉네임/채널/HUD 설정, 로그아웃, 계층형 게임 안내·버전별 패치노트 화면 진입, 현재 화면 채팅 비우기와 개인 채널/관리자 서버 채팅 기록 청소, 전체화면 전환·페이지 확대율 다이얼로그와 권한 10 관리자 새 탭 진입.
- `DisplaySettingsDialog`: 브라우저 자체 확대와 별개인 60~200% 게임 UI 배율을 5% 단위로 선택하고 기기 localStorage에 저장한다. 배율 적용 시 역보정 논리 viewport도 함께 갱신해 사이드바·다이얼로그·전체 화면 overlay가 빈 공간 없이 화면을 채운다.
- `Notification`: 서버 알림과 연결 상태 표시. `length: 0`인 고정 알림은 유지하고 임시 알림은 최근 5개까지만 표시하며, 알림 면은 뒤쪽 HUD·메시지 버튼의 포인터 입력을 가로채지 않는다.
- `ThemeToggle`: 전역 테마 전환.
- `chat/`: ChatNode와 명령 자동완성. 플레이어 메시지 헤더에는 서버가 전송 시점에 스냅샷한 장착 칭호를 닉네임 앞의 작은 `[칭호]`로 표시한다.
- `hud/`: 배치 가능한 게임 HUD. 플레이어 상태 HUD의 이름 행에도 현재 장착 칭호를 반응형 말줄임으로 표시한다.
- `dialog/`: portal 기반 공용 Dialog와 필드 정의형 FormDialog. 필수 select는 첫 option을 초기값으로 사용하며, 검색 선택 목록은 별도 body portal과 viewport 기준 위/아래 배치로 다이얼로그 overflow에 잘리지 않는다.
- `minigame/`: 서버 세션 기반 전체 화면 미니게임 renderer. 낚시는 PC 키보드와 모바일 8방향 조이스틱의 20ms 병합 입력, 등급·0~100% 단색 변화 포획 게이지·채집 영역을 표시하고 종료 frame의 입력·그물·물고기·게이지 proof를 제출한다.
- `security/`: 서버가 발급한 일회성 raster 문제를 표시하고 성공 전에는 닫히지 않는 반복 사냥 사람 확인 오버레이.
- `status-effects/`: 현재 플레이어 상태효과 snapshot을 화염·독·빙결·감전 9-slice 화면 비네트, 독성 HP 색과 마비성 메시지 교란으로 표현하는 입력 비활성 overlay.

컴포넌트 계약이나 하위 폴더 책임이 바뀌면 이 문서와 관련 시스템 문서를 갱신한다. 스타일 변경은 모바일/PC 양쪽 반응형 동작을 확인한다.
